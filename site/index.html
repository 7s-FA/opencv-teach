Python/Tk 프로그램이 GitHub Codespaces에서 직접 실행됩니다. 브라우저는 원본 앱의 화면과 마우스·키보드 조작을 전달합니다.

GitHub 계정으로 원본 앱 실행 →
  1. GitHub 로그인 후 개인 Codespace를 만듭니다. 2코어 구성을 사용하세요.
  2. 첫 실행은 환경 설치로 몇 분 걸립니다.
  3. 준비되면 SO-101 Teach 원본 앱 화면이 열립니다. 자동으로 열리지 않으면 Ports에서 6080의 브라우저 열기를 누르세요.
  4. 사용을 마치면 Codespace를 중지하고, 필요 없는 Codespace는 삭제하세요.

상단 카메라는 저장된 오안착 사진을 입력으로 사용합니다. 검출·검사·티칭 계산은 원본 Python 코드가 수행합니다. 모터는 프로그램의 가상 장치이며 실제 로봇과 연결하지 않습니다.

운영자의 PC가 꺼져 있어도 실행할 수 있습니다. 각 방문자의 GitHub 계정과 Codespaces 사용량을 사용하며, 조직 결제 설정에 따라 청구 주체가 달라질 수 있습니다.
