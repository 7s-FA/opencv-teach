# SO-101 업무 정리 · 2026-10-19

지그별 위치 정합·빠른 채택과 AI 병행 안착 검사를 PC·Pi에 반영했다. 부품 종류·조립 상태는 YOLO 라벨을 우선하고, 정상 안착은 OpenCV·CAD와 마스크 경계로 확인한다. 최종 PC–Pi 실행 파일 120개 일치를 확인했다.

## 지그 검출과 실행 준비

- AI 마스크를 초기·재탐색에 연결하고 현재 영상의 OpenCV 외곽·격자·방향 근거로 운반용 지그를 확인한다. 정상 추적과 AI 재탐색의 역할을 분리했다.
- 완제품 팔레트는 매 관측의 새 AI 마스크에 고정 CAD 외형을 맞춘다. 적재물 뒤 가상 연결선을 실제 경계로 비교하던 원인을 수정하고, 사용자 요청에 따라 최종 CAD 잔차 한도를 3px로 적용했다.
- 운반용 지그와 팔레트 모두 첫 3개 유효 관측이 일치하면 중앙값을 조기 채택한다. 조건이 부족하면 기존 4초 전체 누적·재시도로 돌아간다. 운반용 지그에는 추가 0.5mm·0.5° 안정성 조건을 적용한다.
- 격자 후보 선택·원형 방향 특징·분리 선분 검증을 보완했다. 관측점을 예상 좌표로 옮기거나 기준을 완화하지 않았다.
- 에피소드의 카메라·모델 준비를 팔 연결·리니어 준비와 병행하고 에피소드 안에서 재사용한다. 예열 영상을 위치 관측에서 제외하고 종료·오류·팔 간 인계를 처리한다.

## 안착 검사와 화면

- 지그 검출과 별도로 OpenCV / AI + OpenCV 검사 방식을 선택·적용하도록 했다. PC·Pi 설정 전송과 화면의 실제 적용값을 연결했다.
- 빈 팔레트 평가에 적재물 예상 영역의 배경이 섞이던 문제를 수정하고 구멍 바닥 근거를 추가했다. 실패 당시 저장 영상 3장의 빈 상태 판정은 0/3→3/3으로 개선됐다.
- 정상 A 완제품 마스크에 어두운 배경이 붙던 문제를 수정했다. 동일 영상 3장의 정상 판정은 1/3→3/3, 과거 A 사진 10/10은 유지했다.
- YOLO와 CAD 분류가 다르면 AI 라벨에 맞는 CAD 형상으로 같은 좌표에서 재검사한다. D01은 A 하단+중단으로 분류하면서 각도 19.8°·중심 6.9mm 이탈로 오안착을 유지한다.
- U01의 위치 미확정 원인은 지그 ROI 안 비율 48.4%가 요구 98%에 미달한 것이다. 앱에서 실제 비율·필요 조건을 표시한다. 실제 ROI는 변경하지 않았다.

## 비교·검수 자료

- 같은 AI 입력의 CAD·OpenCV 흔들림, 동일 사진의 반복 AI 추론, 적재 팔레트와 다중 후보 실험을 비교했다. 실험용 다중 후보 정밀 보정은 실사용에 반영하지 않았다.
- 상단 면 라벨 초안을 만들고 v2에서 운반용 지그의 넓은 기존 가시 영역을 유지하며 팔레트 경계를 다듬었다. 사진 6장·객체 10개, 사용자 검수 대기이며 재학습은 시작하지 않았다.
- 실제 정상·오안착·미완성 사진 44장을 53페이지 비교 자료로 정리했다. D01의 최종 라벨 우선 변경은 이후 별도 재생으로 확인했다.

## 검증 요약

| 구간 | 결과 |
|---|---|
| CAD 수정 후 새 카메라 | 빈/A/B 각각 첫 4초 채택 20/20, 이전 B는 7/20 |
| 팔레트 조기 채택 | 새 빈 팔레트 20/20, 내부 중앙값 1.751초. A/B는 이전 영상 재생 각 20/20 |
| 운반용 지그 최종 격자 | 같은 20구간 Pi 재생 18/20→20/20. 새 실물 양성 검증은 남음 |
| 별도 운반용 지그 34구간 | 조기 채택 19→25, 4초 시점 유지 27→27 |
| 최종 라벨 우선 검사 | 45장·53입력: 정상 19 유지, 불충족 32→33, 보류 2→1. 관련 회귀 24개 통과 |
| 배포 | 최종 PC–Pi 실행 파일 120개 일치, Pi D01·U01 실제 추론 확인 |

초기 CPU 검사 시간은 PC 평균 OpenCV·CAD 0.0753초, AI 병행 0.2523초였다. 최종 라벨 우선 재검사 이후 시간은 재측정하지 않았다. 모든 배경에서의 오판 감소율, 독립 실측 정답 대비 절대 위치 정확도, 최종 수정 후 전체 에피소드 성공은 이번 기록으로 확정하지 않는다.
