# YOLO26x·SAM3 최종 비교

실험 완료: 2026-10-17 23:46 KST · 최종 검증·문서 반영: 2026-10-18.

같은 가상+실물 혼합 학습 후 실물 사진 31장·정답 객체 169개로 평가했다. 이번 테스트에서는 YOLO26x-seg TensorRT FP16이 오검출·누락과 속도에서 유리했다. SAM3는 19에포크에서 조기 종료됐고 최적 모델은 14에포크다. 이후 5에포크 동안 개선되지 않아 종료됐으며 최대 20에포크 상한에는 도달하지 않았다.

| 지표 | YOLO26x · FP16 | SAM3 · BF16 |
|---|---:|---:|
| 마스크 AP50–95 | 98.93점 | 98.59점 |
| 맞게 검출한 객체 | 169 / 169개 | 167 / 169개 |
| 오검출 / 누락 | 0 / 0개 | 1 / 2개 |
| 검출 성공 객체 평균 IoU | 96.52% | 97.68% |
| 검출 성공 객체 경계 F1 | 98.71% | 98.91% |

| 전체 처리 중앙값 | 16.50ms | 494.31ms |

YOLO는 AP가 약 0.34점 높고 전체 처리 중앙값이 약 30배 빠르다. SAM3는 검출한 객체의 평균 IoU가 약 1.16%p 높지만 B 하단 2개(C207·C304)를 놓치고 A 중단 1개(C188)를 추가 검출했다. 검출 성공 객체만의 IoU·경계 F1에는 놓친 물체가 포함되지 않는다.

## 학습 방식 선택

| YOLO 학습 방식 | 실물 검증 AP | 실물 테스트 AP | 테스트 오검출 / 누락 |
|---|---:|---:|---:|
| 가상+실물 혼합 학습 | 98.23 | 98.93 | 0 / 0 |
| 가상→실물 순차 학습 | 97.53 | 97.20 | 1 / 1 |

- 같은 원본 분할의 실물 검증 30장으로 방식을 결정한 뒤 테스트 31장을 평가했다. 두 방식의 검증 오검출·누락은 0개였지만 순차 AP 개선 조건을 충족하지 않아 혼합을 유지했다.
- 순차 학습은 원본 → 가상 960장(59에포크 종료·최적 34) → 실물 243장(48에포크 종료·최적 38)이다. 실물 단계는 상한 없이 10에포크 연속 미개선 시 종료했다.
- 기존 40에포크 결과의 EMA 텐서 1,228개가 저장 정밀도 기준으로 재현됨을 확인하고 연장 학습했다.
- SAM3는 원본 기본 모델에서 혼합 1,203장으로 시작했다. 기존 실물 전용·시험 학습 모델로 초기화하지 않았으며, 일시정지 후 optimizer와 난수 상태를 포함해 재개했다.
- SAM3 최적 혼합 검증 150장(가상 120+실물 30) AP는 99.813점이다. 실물 전용 검증 30장 AP 98.476점, 최종 실물 테스트 AP 98.592점과 구분한다.

## 측정 조건과 해석 범위

- RTX 4070 SUPER, batch 1, CPU 4스레드, 실물 테스트 31장×3회. 전체 처리 시간은 전처리·추론·마스크 처리·RLE 변환·중복 제거를 포함한다. 파일 읽기·카메라·표시·전송 시간은 제외한다.
- 입력은 YOLO 960 / SAM3 1008, 정밀도는 FP16 / BF16+TF32다. 같은 이미지·분할을 사용했지만 optimizer·증강·학습량·동결 범위는 다르므로 동일 계산량의 구조 비교가 아니다.
- SAM3의 131.08MB는 학습한 부분만 저장한 파일이며 기본 모델 약 3.45GB가 별도로 필요하다.
- GPU 전체 사용량 표본 최대는 YOLO 1.888GB, SAM3 6.243GB다. 디스플레이·다른 프로세스가 포함되고 모델 로드 전 기준도 1.383GB / 1.709GB로 달라 순수 모델 점유량으로 해석하지 않는다.
- 현재 가중치·원본 초기화·데이터 분할 해시, 공통 검증·테스트 ID와 정답, 평가·후처리 코드, 시간 표본을 확인했다. 테스트 결과로 설정이나 임계값을 조정하지 않았다.
- 한 촬영 환경에서 분리한 작은 테스트셋이며 일부 클래스는 정답 2개뿐이다. 새 날짜·조명·카메라 일반화와 실물 로봇 작업 성공은 미검증이다.
- 이번 YOLO26x·SAM3는 실제 앱·카메라·로봇에 배포하지 않았다. [이전 YOLO26s NCNN·Pi 5 비교](../2026-10-16/README.md)와 모델·장치·평가 조건이 다르다.

13클래스별 AP·IoU·경계 F1, 신경망·전체 처리 중앙값/P95 및 근거는 전체 보고서에 포함했다.
