조건·해석 범위
YOLO의 테스트 AP가 0.339점 높고, 전체 처리 중앙값은 약 30.0배 빠르다. SAM3의 검출 성공 객체 IoU는 1.155%p 높다.
SAM3 오류: B 하단 누락 2개(C207·C304), A 중단 오검출 1개(C188). YOLO 혼합은 FP/FN 0개. 순차 YOLO는 C304에서 B 하단 누락·B 상단 오검출 각 1개.
검출 성공 객체만의 IoU·경계 F1은 오검출·누락을 제외한다. 누락을 0점으로 반영한 경계 F1도 함께 제시했다. AP는 단순 정답률이 아니다.
두 모델은 같은 가상 960장+실물 243장으로 학습하고 기존 분할을 유지했다. 입력(YOLO 960/SAM3 1008), 정밀도(FP16/BF16+TF32), optimizer·증강·학습량·동결 범위는 다르므로 동일 계산량의 구조 비교가 아니다.
RTX 4070 SUPER, batch 1, CPU 4스레드. 속도는 실물 테스트 31장×3회, 신뢰도 0.5에서 측정했다. 이미지는 메모리에 미리 읽었으며 카메라·파일 읽기·표시·전송은 제외한다. 전체 처리는 전처리·모델 실행·마스크 처리·RLE 변환·중복 제거를 포함한다.
신경망 계산 시간은 통신 지연이 아니다. YOLO는 런타임 inference 계측, SAM3는 CUDA 이벤트로 이미지 인코더 1회와 텍스트·grounding 13개 프롬프트의 합을 측정했다. 계측 범위 차이를 고려하고 실제 처리 비교는 전체 시간을 우선한다.
GPU 메모리는 표본으로 읽은 장치 전체 사용량이며 디스플레이·다른 프로세스를 포함한다. 모델 실행 직전 기준은 YOLO 1.383GB, SAM3 1.709GB였다. Torch 할당량만으로 TensorRT와 비교하면 외부 할당이 빠지므로 사용하지 않았다.
SAM3의 131.08MB 파일은 학습한 부분만 저장한 adapter다. 실행에는 기본 모델 3,450.06MB가 추가로 필요하다. YOLO 130.35MB는 TensorRT 엔진 전체다.
학습 방식과 체크포인트 선택에 테스트를 사용하지 않았다. 테스트 결과를 본 뒤 임계값·후처리·모델 선택을 조정하지 않았다. 한 촬영 환경에서 나눈 작은 테스트셋이며 새로운 조명·카메라·날짜의 일반화나 실물 로봇 작업 성공률은 미검증이다.
현재 앱·카메라·로봇에는 배포하지 않았다.
