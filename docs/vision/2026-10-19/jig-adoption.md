# 지그 인식·빠른 위치 채택

기준일: 2026-10-19. 현재 작업대의 AI 마스크 모드는 운반용 지그와 완제품 팔레트에 서로 다른 정합 방식을 사용한다. 두 지그 모두 검증된 첫 3개 관측이 일치하면 전체 획득 시간을 기다리지 않고 중앙값을 채택한다.

## 지그별 역할

| 대상 | 위치·방향을 구하는 방법 | 조기 채택 |
|---|---|---|
| 운반용 지그 | 초기·재탐색은 현재 YOLO 마스크로 영역을 찾고, OpenCV가 실제 외곽·격자·앞뒤 방향을 확인. 정상 추적도 현재 영상 사용 | 첫 3회의 품질 조건 + 모든 관측 쌍의 안정성 확인 |
| 완제품 팔레트 | 매 관측마다 새 YOLO 마스크에 고정 STL 외형을 맞춰 중심·각도 계산. RGB 외곽·구멍·색상 검증을 추가하지 않음 | 첫 3회의 AI·CAD 검증 + 모든 관측 쌍의 일치 확인 |

AI가 반환한 경계 상자 중심을 그대로 이동 좌표로 쓰지 않는다. 지그의 위치·각도 채택과 부품의 정상 안착 판정도 구분한다.

## 첫 3회 채택 조건

| 조건 | 운반용 지그 | 완제품 팔레트 |
|---|---|---|
| 관측 | 서로 다른 현재 영상 3개 | 서로 다른 현재 영상에서 새 AI 추론·CAD 검증 3회 |
| 영상 좌표 일치 | 중심 ≤5px, 방향 ≤3°, 면적 비율 ≤1.12 | 동일 |
| 추가 실좌표 일치 | 모든 관측 쌍의 중심 ≤0.5mm, 방향 ≤0.5° | 별도 0.5mm·0.5° 조건 없음 |
| 개별 품질 | 검증된 n 모델·지그 형상·1280×720, 단일 후보, 외곽 보정·격자·360° 방향 및 커버리지·크기·방향 신뢰도 | 단일 후보, 고정 CAD 치수·보정·ROI·수렴·잔차 기준 |
| 대표값 | 위치·방향 중앙값 | 위치·방향 중앙값 |

첫 3회 중 미검출·불일치·중복·검증 부족이 있으면 해당 구간은 기존 전체 누적 판단으로 넘어간다. 뒤에서 잘 맞는 3개만 골라 조기 채택하지 않는다. 현재 Pi 설정은 **4초 획득·최대 5회 시도**이며 기존 과반 그룹·중앙값, 최신 관측, 유지·실행 고정 조건을 유지한다. 예열 영상·이전 마스크·이전 채택값을 새 관측으로 세지 않는다. 위치가 채택돼도 이동 전 검증은 별도로 수행한다.

## 가려진 팔레트와 CAD 정합

B 완제품 뒤로 팔레트가 가려졌을 때, 마스크의 양 끝을 잇는 가상의 볼록 외곽선이 실제 경계처럼 사용돼 정합을 거부하는 문제가 있었다. 현재는 마스크로 관측되는 경계만 사용한다.

- 부분 정합은 관측 외곽 60% 이상과 충분히 긴 CAD 경계 두 개 이상의 지지가 필요하다.
- 각 경계 길이의 절반 이상이 관측되고 서로 독립적인 방향이 있어야 한다. 평행한 경계만 있으면 위치를 확정하지 않는다.
- 최종 CAD 잔차 한도는 사용자 요청으로 설정한 **3px**다. 원인 수정과 허용치 변경을 구분한다.
- 지그 검출 ROI에는 팔레트 마스크의 **98% 이상**이 포함돼야 한다. 이 조건은 부품 안착 경계의 1% 기준과 다르다.

U01의 저장 사진은 ROI 안 비율이 **48.4%**여서 안착검사 이전에 지그 위치가 미확정됐다. 같은 영상에서 진단용으로 ROI 제한만 제거하면 CAD 정합은 통과했다. 실제 ROI 설정을 변경한 결과는 아니다. 앱은 범위 안 비율과 필요 비율을 이유로 표시한다.

## 운반용 지그의 격자 근거

정밀 외곽 보정 후에는 실제 영상에서 조건을 통과한 격자 후보들을 비교한다. 초기 탐색의 상위 후보 제한으로 더 정확한 교차점이 버려지지 않도록 했다. 한 줄이 두 교차점 사이에서 끊겨도 각 교차점 주변의 독립적인 선분·영상 가장자리 근거가 있으면 검증한다. 관측 좌표를 예상 좌표로 옮기거나 없는 선을 채우지 않는다. 격자 정렬 5mm와 조기 채택 0.5mm·0.5° 조건은 유지한다.

## 카메라·모델 준비

명령 설정 적용 직후 카메라·모델 준비를 팔 연결·리니어 준비와 병행한다. 실제 영상으로 모델 추론 1회를 마치면 준비 완료로 표시한다. 준비 뒤 누적값과 대기 영상을 비우고 새 측정을 시작한다. 에피소드 안에서는 카메라·모델을 재사용하고, 측정 사이에는 지그 추론만 멈춘다. 종료·오류·팔 간 인계 때는 정상 정리 절차를 거친다.

Pi의 한 번의 준비·재사용 비교는 2.632초 → 0.083초였다. 최초 초기화 비용이 사라진 것이 아니라 다른 시작 작업과 겹치고 반복 초기화를 줄인 것이다.

## 확인 결과

| 확인 | 결과 | 의미 |
|---|---|---|
| CAD 수정 후 새 카메라 측정 | 빈 상태·A·B 각각 첫 4초 채택 20/20. B는 이전 7/20 | 현재 배치·조명에서 확인 |
| 팔레트 3회 채택 새 실물 측정 | 빈 팔레트 20/20, 내부 채택 중앙값 1.751초 | 카메라·모델 최초 준비 제외 |
| 팔레트 A/B 저장 기록 재생 | 각각 20/20, 중앙값 A 1.737초·B 1.829초 | 새 A/B 실물 촬영과 구분 |
| 운반용 지그 최종 격자 수정 | 같은 20구간 Pi 재생에서 조기 채택 18/20 → 20/20 | 새 실물 양성 검증은 남음 |
| 별도 34구간 전후 비교 | 조기 채택 19/34 → 25/34, 4초 시점 채택 유지 27/34로 동일 | 영상당 평균 처리는 0.302초 → 0.333초 |

조기 채택률 개선을 영상당 추론 속도 개선과 혼동하지 않는다. 반복 편차와 기존 누적값의 일치도는 독립 측정 장비에 대한 절대 위치 정확도가 아니다.
