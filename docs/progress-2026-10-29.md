# 조립대 작업 요약 · 2026-10-29

10월 20일 이후 27일까지 반영한 조립대 실행·검사·조회·녹화 변경을 정리했다. 이 문서의 게시일과 아래 검증 수행일을 구분한다.

## 현재 반영 내용

- **검사와 다음 이동 병행:** 체크포인트에서 필요한 새 영상을 확보한 뒤 해당 영상의 판정과 다음 동작을 병행한다. 불합격·시간 초과 시 HOLD/PAUSED를 유지하고 마지막 판정이 끝나기 전에는 전체 완료를 알리지 않는다.
- **같은 작업의 중간 재개:** `RESTART` 또는 앱의 재검사 버튼으로 새 영상을 검사한다. 처음 채택한 지그·팔레트 좌표와 기존 경로를 유지하고, 확인된 완료 스텝을 제외한 나머지만 실행한다. 초기 채택 실패와 새 에피소드는 새 위치 확보가 필요하다. 연결 복구만으로 재개하지 않는다.
- **준비 대기·재접속:** 정상 작업 후 카메라·모델 준비를 3분 유지한다. 조회만으로 대기 시간을 늘리지 않으며, 상태가 불확실하면 타이머만으로 토크를 해제하지 않는다. 중단·재개·만료·기록 저장 경합과 재조회 오류를 보완했다.
- **PC 협력 실행:** `PC_BUILD_LOAD_A/B`는 PC의 YOLO26n TensorRT FP16·CAD 판정을 사용하고 Pi가 장치·작업 순서·판정 유효성·정지를 담당한다. 기존 Pi 명령과 검사 기준을 유지하며, PC 장애 시 추론 경로를 자동 전환하거나 작업을 자동 재개하지 않는다.
- **실시간 작업 조회:** 외부 실행의 상태·검사·채택 위치를 기존 카메라 영상과 함께 조회한다. 결과는 실제 표시 시점부터 2초 유지하며, 작업 전환 중에는 직전 결과임을 구분한다. 기본 영상 요청은 10 FPS이고 실측 수신 속도는 약 7.53 FPS였다. 12 FPS 달성 결과는 아니다.
- **원본·검사본 동시 녹화:** 검사본은 화면에서 선택한 확대·윤곽·판정 표시를 사용한다. 별도 하단 설명 띠를 제거했다. 사용자가 녹화를 끝내기 전에는 일시적인 수신 중단·작업 전환·화면 이동으로 종료하지 않는다. 지연 구간은 마지막 원본·검사 프레임을 반복해 실제 경과 시간을 유지하고 복구 후 같은 파일에 이어서 저장한다. 앱 종료 또는 저장 오류는 별도 처리하며 수신 변화·종료 사유를 기록한다.
- **운영 화면·기록:** 밝은 회청색·청록색 UI, 도움말, 검사 지정 스텝과 중단 당시 진행·완료 스텝 구분, 판정 소요 시간과 원본 증거 기록을 반영했다.
