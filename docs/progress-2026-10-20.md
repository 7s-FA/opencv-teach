# 업무 정리 · 2026-10-20

지그 위치 채택·안착 검사·시작 준비를 정리하고 동시 작업이 반영된 PC·Pi와 관제 연동을 점검했다. [현재 적용 구조와 Pi 비교](vision/2026-10-20/README.md)에 검사 선택·성능·제한을 정리했다.

## 반영한 내용

- AI 라벨 + CAD를 기본 안착 검사로 적용하고 추가 AI 마스크 경계 합격 조건을 제외했다. 슬롯 연결·CAD 안착·연속 관측 기준은 유지한다.
- 조기 채택 후 위치 변경 시 미고정 좌표를 무효화한다. 전체 지그에서 ROI·거절 이유를 조회하고 개별 화면에서 범위를 편집한다.
- 카메라·모델 예열, 시작 검사·고정 좌표 경로 계산·리니어 완료 확인을 가능한 구간에서 병행한다. 동일 영상의 AI 결과를 공유하며 실제 관측 횟수·신선도·시간 제한을 유지한다.
- PC 관제의 PREPARE_HOME·CLEAR_ERROR와 BUILD_DONE 처리, 리니어 하드웨어 PWM, 실행 문서를 맞췄다.
- 전체 지그 영상·검사표·촬영 삭제 대상·주요 버튼을 정리하고 사진 기준 MuJoCo·Isaac Sim 외관을 반영했다.
- 누락된 PC·Pi 추론 환경 의존성, 오래된 테스트 자료·문서·백업 위치를 정리했다.

## 작업대 검증 기록

| 범위 | 결과 |
|---|---|
| 전체 회귀 | 271개 모듈·1,820개 검사 수집, 선택 제외 6개. 초기 실패 4개를 테스트 자료 수정·관련 재검사로 해소 |
| 전체 점검 시 PC·Pi | 실행 파일 122개와 소스·문서 153개, 활성 에피소드·실행 설정·유효 프로필 대조 |
| 시작 준비·경로 병행 | 고유 검사 60개 / 관련 검사 148개 통과, 저장 영상 판정 행 일치 |
| UI 개선 | 관련 60개 검사·최대화 화면 7개 확인 |
| 3D 외관 | 관련 27개 검사·Isaac 3시점·1920×1080 앱 확인, 관절 초기 자세 18개·정적 충돌면 11개 유지 |
| 네 모델 | PC YOLO26x TensorRT FP16·SAM3 BF16, Pi YOLO26s·YOLO26n NCNN FP16 추론 확인 |

검사 묶음에는 중복이 있어 합산하지 않는다. 위 수치는 원본 작업대의 각 보고 시점 기준이다. 실물 이동은 저장 안전 자세 복귀·토크 해제 범위였고, 새 A/B 전체 조립·운반은 실행하지 않았다. Pi 독립 GUI는 운영 대상이 아니며 실행 검증하지 않았다.

## 공개 저장소 확인

공개 배포용 Windows 파일·모델 로딩, Linux 전용 장치 접근 분리, 예제 에피소드와 설정을 보존했다. 최신 소스와 표시 자산을 반영하고 관제 클라이언트를 함께 제공한다. 공개 저장소 검증은 [별도 기록](vision/2026-10-20/publish-validation.json)에 남긴다. Git 소스 갱신과 다운로드 릴리스 갱신은 별개이며 이번 작업은 새 릴리스를 만들지 않는다.
