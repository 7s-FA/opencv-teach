# SO-101 개발 현황 · 2026-10-16

현재 티칭 앱의 구현·검증, 인식 모델 비교, 별도 시뮬 실험과 설계 기록을 구분한다.

## 2026-10-13

- 전체 공장 맵·버거 운반 경로 도면 보완. 출차·경유·진입 구간을 분리해 경로 겹침을 줄이고 Isaac Sim·MuJoCo 실행 묶음과 도면을 Google Drive에 갱신.
- 티칭 앱 3D 결과 수신을 개선하고 바닥 반사 처리의 불필요한 변환 축소. 같은 화면 조작에서 표시 간격 95백분위가 약 70~71ms에서 41~44ms로 감소. 관련 38개 검사 통과.
- Isaac Sim 전체 시점·카메라 모니터 전환과 시작·프레임 처리 개선. 전체 시뮬 첫 화면 준비 시간 약 54.2초→27.5초. 화면 처리 측정과 물리 실시간 실행 성능은 구분.
- 현재 Pi의 팔2 A/B 조립·팔3 A/B 운반 에피소드 기준으로 시뮬 연속 실행 연결. 조립→리니어 이동→팔3 팔레트 적재→리니어 복귀와 단계별 알림 구성.

**검증 범위:** 당일 보정의 A/B 연속 실행 성공 기록은 이후 10월 14일 영상·인코더 기준으로 모델을 교체하면서 이전 조건의 결과로 보관. 최신 모델의 조립 성공 근거로 사용하지 않음.

**남은 작업:** 영상·인코더 기준 관절각과 접촉 모델의 정합 보완.

## 2026-10-14

- 팔2 A/B 실물 시연 영상과 모터 틱을 수집·대조하고 시뮬 틱–관절각 대응 재보정. 원본 티칭 틱·실물 FK/IK·보정 파일 유지. A/B 공통 오프셋과 비율 적용.
- 홀더에 가려진 영역·잘린 손가락 마스크를 제외하고 자유 이동 프레임·관절축 확인점으로 영상 정합 평가. 영상 외곽 오차 개선과 실제 3D 위치 오차는 구분.
- 모터 관측 지연·정지 오차·부하 기록을 반영하고 TPU 손가락의 수동 탄성 근사 추가. 실제 인필 기준 슬라이싱 질량 반영. 탄성·접촉 계수는 시뮬 추정값으로 관리.
- 수정 모델로 A 28스텝·B 32스텝 재생. A는 하단·중단 파지 불완전, B는 세 부품 상승·중단 삽입·상단 정렬을 확인했으나 하단 안착 오차가 기준을 넘어 전체 조립 실패.

**검증 범위:** 원본 보호 파일 4,502개 해시 보존과 관련 오프라인 검사 63개 통과. 새 모델의 리니어·팔3 연속 운반 성공은 미확인. 시뮬 실패를 사용자가 확인한 실물 A/B 에피소드의 실패로 해석하지 않음.

**남은 작업:** 집게 변형·접촉과 운반 구간의 카메라·관절 정합 개선.

## 2026-10-15

- 티칭 앱 전체 점검과 화면 최적화. 카메라 프레임 시각 비교, 촬영 직전 연결 해제, 긴 안내 잘림, 불필요한 목록·버튼 갱신 수정. 최대화 화면 22개 확인, 콜백 오류 0건.
- 전체 회귀 1,609건 실행 후 남은 화면 크기 관련 실패를 수정하고 관련 22건 재검사 통과. 두 팔 연결·저장 안전 자세 명령·토크 해제 확인. 시작부터 안전 자세 부근이었으며 A/B 조립·운반은 이번 점검에서 실행하지 않음.
- 사진 촬영 버튼을 좌클릭 저장·우클릭 선택 사진 묶음 삭제로 변경. 원본·표시본·판정 기록을 함께 처리하고 중복 우클릭 방지. 촬영 뒤 버튼 문구·활성 표시의 빠른 전환 제거. 관련 37개 검사 통과.
- 13클래스 가상 데이터 1,200장 구성. 리니어 전진·후진·중간 각 400장, 조명 밝기·색온도·방향, 부품 위치·조립 상태 변주. 학습 960 / 검증 120 / 테스트 120장 분리.
- YOLO26n-seg 가상 학습 기준 결과 보관. 실물 사진 304장 확보 후 SAM 3·색상·윤곽 기반 마스크 후보 생성과 검토 도구 구성. 후보 마스크를 바로 정답으로 취급하지 않고 검수 단계로 분리.
- 팀원에게 받은 팔1 A/B ACT 모델과 학습 자료를 창고 시뮬에 연결. 저장된 입력·출력 변환, 카메라와 정책 실행 기록을 구성하고 원본 모델·보정 파일 보존.

**검증 범위:** 실물 점검은 안전 자세 명령까지. 가상 테스트 성능과 실제 카메라 성능, ACT 추론 실행과 안정 운반 성공을 구분.

**남은 작업:** 실물 마스크 검수 완료 후 실물·가상·혼합 모델 비교. 팔1 카메라·관절·접촉 정합 보완.

## 2026-10-16

- 실물 304장·13클래스·1,675개 객체의 마스크를 사용자 표시 지점과 원본 사진 기준으로 수정. 가시 표면·구멍·제품과 지그 경계를 구분하고 v7 최종 데이터 묶음 생성. 학습 243 / 검증 30 / 테스트 31장 분리.
- YOLO26s-seg 실물·시뮬레이션·혼합 학습 완료. 각 모델을 원본 PyTorch, NCNN FP16, ONNX INT8 혼합 정밀도로 준비해 총 9종을 같은 입력 960과 공통 테스트로 비교.
- 라즈베리파이 5에서 9종 모두 CPU 4스레드·준비 3회·측정 12회 실측 완료. 모델 파일과 파이 실행 파일 해시 일치 확인.
- 혼합 학습 FP16 권장: 실물 윤곽 점수 94.76, 시뮬 94.16, 실물 169개 객체에서 잘못 검출·누락 0개. 처리 시간 1.223초/장, 최대 메모리 409.7MiB. 혼합 INT8은 실물 점수 95.20이나 처리 시간 1.959초/장·메모리 625.0MiB.
- 비교표를 인식 성능·파이 실행 성능으로 분리하고 한글 항목·부품명·그래프 적용. FP16(16비트 실수)과 INT8(8비트 정수 혼합)을 명시하고 추천 모델·보고서 묶음 보관.
- 팔1 ACT 시뮬의 영상 특징·관절 대응·TPU 접촉 후보 보정. A의 집게 관측값이 약 47에서 멈추던 원인을 접촉·정체 유지와 다음 열기 요청으로 구분. 보정 후보에서 약 27.1까지 닫힘을 확인했지만 A/B 안정 운반은 미해결.
- 와플 지게차 v11 설계·출력 패키지 정리. 한쪽 가이드·롤러 4개·MF106ZZ 베어링 2개, A/B 독립 창고 구성. 20종·39개·7개 베드, 슬라이서 예상 약 719g·29시간. 카메라·라이다 기존 위치를 유지하고 형상 간섭·공차·가림 검토.

**검증 범위:** YOLO 파이 측정은 카메라·그리기·전송·화면 표시 제외. 추천 모델의 티칭 앱 판정 통합·반복 실물 운전은 미완료. 팔1 시뮬 보정은 진행 중. 지게차는 CAD·슬라이싱까지 확인했으며 실제 출력·조립·하중·센서 성능은 미검증.

**남은 작업:** 추천 FP16의 앱 연결과 새 촬영 조건 평가. 팔1 운반 구간의 기하·접촉 정합, 지게차 출력·조립 확인.
