# 부품·조립 상태 검사 ROI 기준

이 기준은 현재 A/B STL, 운반용 지그 조립 모델, 리니어 캐리지 모델, 완제품 팔레트 모델과 SO101_rl의 B 조립 장면에서 계산했습니다. **실제 카메라 검사 영역과 합격 공차를 확정하기 전의 CAD 기준 데이터**이며, 로봇 동작이나 자동 PASS/FAIL에는 아직 연결하지 않았습니다.

- 기준 데이터: `roi_reference.json`
- 전체 배치: `previews/roi_overview.png`
- A 단계별 가시 영역: `previews/assembly_stages_A.png`
- B 단계별 가시 영역: `previews/assembly_stages_B.png`
- 단계별 label PNG: 색상 사진이 아니라 CAD 위쪽 투영의 부품 구분 마스크입니다. 원본 크기 350×350, 0.2mm/픽셀, 중심 원점, 영상 위쪽이 로컬 +Y입니다. 실물 RGB 정상 템플릿으로 직접 사용하지 않습니다.

## 1. 좌표와 각도

길이는 mm, 각도는 도입니다. +Z에서 내려다봤을 때 반시계가 +회전입니다. 화면 픽셀 좌표의 Y축 방향과 혼동하지 않습니다.

- **운반용 지그:** 운반판 XY 중심이 원점, 아랫면 Z=0. 긴 방향이 X, 짧은 방향이 Y입니다.
- **리니어:** 캐리지 중심을 기준으로 팔레트 중심이 `(-40, 0, 9.4)`, `(40, 0, 9.4)`입니다. 각 팔레트의 부품/단계 ROI는 해당 팔레트 중심을 다시 원점으로 사용합니다.
- **완제품 팔레트:** 70×70mm 모델 중심이 원점, 바닥 Z=0이며 현재 모델은 중앙 한 자리입니다.

운반용 지그 검출 좌표를 사용할 때는 검출의 `mesh_yaw_offset_deg`까지 포함한 CAD 방향으로 ROI를 변환해야 합니다. RL 기준 장면에는 180° 보정이 있으며, 이 값을 빠뜨리거나 두 번 적용하면 A/B 줄과 좌우 부품이 바뀔 수 있습니다. 방향이 해소되지 않은 운반판에는 검사 ROI를 확정하지 않습니다.

변환식은 `세계 XY = 검출 원점 XY + R(검출 yaw + mesh_yaw_offset) × 지그 로컬 XY`입니다. 카메라 픽셀 변환에는 추가로 카메라 보정과 **부품 높이**가 필요합니다. 운반판 테두리 평면만으로 높이 있는 부품을 동일하게 투영하면 시차 오차가 생깁니다.

## 2. 운반용 지그: 원점 추종 ROI

아래 좌표는 CAD 기준입니다. 카메라에서의 왼쪽/오른쪽이 아니라 운반판 로컬 X/Y를 뜻합니다. ROI 크기는 **부품 외곽에 각 방향 3mm 검색 여유를 추가한 초기값**이며 합격 허용 오차가 아닙니다.

| 위치/부품 | 중심 X, Y | 기준 yaw | 부품 외곽 | 초기 검색 ROI |
|---|---:|---:|---:|---:|
| A 상단 | -72, -36 | 90° | 50×50 | 56×56 |
| A 중단(구형) | 0, -36 | 판정 제외 | 약 30×30 | 약 36×36 |
| A 하단 | 72, -36 | 90° | 50×50 | 56×56 |
| B 상단 | -72, 36 | 90° | 50×50 | 56×56 |
| B 중단 | 0, 36 | 90° | 31.9×31.9 | 37.9×37.9 |
| B 하단 | 72, 36 | 90° | 50×50 | 56×56 |

받침의 간격은 72mm, 각 받침 판은 68×68mm입니다. 하단 받침의 설치 방향에는 기존 모델의 추정이 포함되어 있으므로 기준 사진으로 확인해야 합니다. B 상단의 뒤집힌 방향은 기존 RL 장면의 설정과 일치합니다. A 상단의 뒤집힌 방향·접촉 높이는 CAD 안착 후보이며 실물 확인이 필요합니다.

검사는 선택한 제품 A 또는 B의 세 부품을 대상으로 합니다. 다른 제품 줄의 부품을 현재 제품의 필수 수량에 포함하지 않습니다. 검사 항목은 부품 유무, 부품 중심의 원점 대비 위치, 특징으로 구분 가능한 회전/뒤집힘, ROI 밖으로 벗어난 부분입니다. 구형 A 중단은 회전각을 합격 조건으로 사용하지 않습니다. 정사각형 외곽만 보이면 90° 차이를 구별할 수 없으므로 유일한 방향 판정에는 구멍·비대칭 특징 또는 기준 사진이 필요합니다.

## 3. 리니어 위 팔레트: 위치와 공정 단계별 ROI

리니어가 같은 작업 위치에 멈춘 상태에서 두 팔레트의 고정 영상 ROI를 각각 등록합니다. 전진·후진 위치에서 검사한다면 두 위치의 영상 등록을 구분합니다. 이 데이터는 캐리지 로컬 기준이며, 레일 중심 좌표나 시뮬레이션 세계 좌표를 그대로 픽셀 ROI로 사용하지 않습니다.

B RL 장면은 모터에서 먼 팔레트(index 1)를 사용합니다. 실제 A/B 레시피가 사용하는 팔레트는 현장 영상·티칭과 연결해서 선택해야 하므로 자동 선택은 넣지 않았습니다. 먼저 팔레트 기준 모서리의 위치가 맞는지 확인하고, 어긋났으면 제품 불량이 아니라 위치 등록 실패 `UNKNOWN`으로 구분합니다.

**부품이 누적되는 순서에 따라 기준을 바꿉니다.**

| 단계 | ROI 및 직접 검사 | 이전 결과 처리 |
|---|---|---|
| 빈 팔레트 | 중심 부품 영역이 비었는지, 팔레트 기준 모서리가 보이는지 | 새 제품/작업 ID로 이전 결과 초기화 |
| 하단 안착 | 중심 56×56 검색 영역에서 하단 유무·외곽·중심·방향 | 빈 상태 검사와 올바른 작업 순서 확인 |
| 중단 삽입 | A는 약 36×36, B는 37.9×37.9 영역에서 새 중단 확인. 노출된 하단 테두리도 유지되는지 확인 | 하단 PASS를 같은 제품 ID에 보존 |
| A 상단 결합 | 56×56 영역의 상단과 **중앙에 계속 보이는 구형 중단**을 함께 확인 | 가려진 하단을 누락으로 판정하지 않음 |
| B 상단 결합 | 56×56 영역의 상단 외곽·중심·방향 확인 | 가려진 하단·중단은 해당 단계의 PASS 기록 요구. 마지막 사진만으로 내부 정상 판정 금지 |

CAD 위쪽 투영에서 A 최종 상태는 상단 약 1,962mm²와 구형 중단 약 531mm²가 보입니다. B 최종 상태에서는 상단 약 2,493mm²가 보이고 하단·중단은 가려집니다. 이 숫자는 모델·0.2mm 격자의 결과이며 실제 영상의 픽셀 면적 합격 기준이 아닙니다.

단계별 마스크에는 노출된 부품의 영역과 label을 저장했습니다. 상단을 올린 뒤 하단 또는 중단의 전체 외곽을 다시 찾는 방식은 사용하지 않습니다. 한 단계의 검사 실패·판단 불가 상태에서 다음 단계 검사를 성공 처리하지 않습니다. 프레임이 팔·그리퍼에 가렸거나 흔들렸다면 새 정상 사진으로 갱신하지 말고 `UNKNOWN`으로 둡니다.

### 높이 기준은 A/B를 구분

아래 값은 부품 간 수직 첫 접촉을 계산한 CAD 값입니다. 실제 삽입 깊이·출력 공차·연성 변형의 측정값이 아닙니다.

| 항목 | A | B |
|---|---:|---:|
| 하단의 팔레트 바닥 대비 안착 Z | 3.55mm | 3.55mm |
| 중단 바닥의 하단 원점 대비 Z | 약 3.05mm | 약 2.05mm |
| 뒤집힌 상단 최저점의 하단 원점 대비 Z | 약 15.35mm | 약 22.10mm |
| 하단 윗면과 상단 최저점의 차이 | -2.65mm | +1.60mm |

A의 -2.65mm는 상단 형상이 하단 높이 범위에 들어가는 CAD 배치를 뜻하며 음수 틈새를 검사하라는 뜻이 아닙니다. **B의 1.6mm 간격 기준을 A에 복사하지 않습니다.** 상부 카메라로 직접 보이지 않는 높이·틈새는 측면 영상 또는 별도 센서 없이는 확정하지 않습니다.

시뮬레이션의 XY 허용치(하단 2mm, 중단/상단 1.5mm), 하단 yaw 5°는 비교용 후보로만 저장했습니다. 실물 합격 공차로 자동 적용하지 않습니다. 실제 카메라 정합 오차와 정상/불량 샘플을 측정한 뒤 별도로 확정해야 합니다.

## 4. 완제품 팔레트: 원점 추종 ROI

중앙 `(0,0)`에 완제품을 놓는 기준입니다. A/B 모두 외곽이 50×50mm이므로 기본 검색 ROI는 56×56mm입니다. 기준 yaw는 팔레트 축과 나란한 0°이며 정사각형 외곽 기준으로는 90° 대칭입니다.

확인 항목:

- 그리퍼가 제품을 놓고 검사 영역 밖으로 빠졌는지
- 제품이 중앙에 남아 있고 위치·방향이 맞는지
- A는 상단과 중앙 구형 부품의 예상 노출이 보이는지
- B는 상단 외관이 맞고, 같은 제품 ID의 조립 단계 PASS가 모두 있는지
- 이전 제품 사진·이전 프레임을 현재 제품 완료로 재사용하지 않는지

완제품 팔레트는 현재 CAD상 70×70 한 자리입니다. 여러 팔레트를 추가하면 각각 별도의 지그 원점/인스턴스 ID를 부여합니다. 운반판의 3×2 부품 배열을 완제품 팔레트에 그대로 적용하지 않습니다.

## 5. 시뮬레이션에서 가져온 것과 제외한 것

B 하단·중단·상단 STL 해시가 `SO101_rl/outputs/assembly_current_12/scene.json`과 일치함을 확인했습니다. 같은 `seating_height`와 상단 뒤집힘 계산을 사용했고 B 안착 높이·삽입 높이·상단 높이를 기존 RL 결과와 비교했습니다.

다음은 시뮬레이션 배치 조정값이어서 실물 ROI에 적용하지 않았습니다.

- 운반판 전역 이동 `(16.66, -2.55, 0)`mm와 yaw `-8°`
- B 부품별 받침 이동/회전 보정
- 리니어 수신 팔레트 이동 `(7.7, 3, -8)`mm

원본 출처와 SHA-256은 JSON에 기록했습니다. A는 현재 RL의 B 조립 성공을 그대로 검증 근거로 삼지 않고 **CAD로 유도한 별도 기준 후보**로 구분했습니다.

## 6. 영상 분류와 공정 판정의 범위

`roi_reference.json`은 CAD 원본입니다. 이 파일의 `inspection_enabled: false`와 선행 PASS 조건은 공정 합격·동작 차단이 활성화되지 않았다는 뜻입니다. PC 화면의 **윗면 형상 분류**는 별도로 동작합니다. 티칭 기록, 카메라 보정, 지그 검출 설정, 로봇 제어와 Pi 프로토콜은 수정하지 않습니다.

`shape_templates.npz` / `shape_templates.json`에는 CAD에서 추출한 58개 윗면 기준이 있습니다. 운반 지그 A/B 하단·중단·상단의 빈 상태/정상 부품/다른 종류 부품 상태, 리니어·완성품 팔레트 A/B의 빈 상태·하단·중단·상단 조립 상태입니다. 높이 변화, 노출된 재질 영역, 중앙 구멍과 외곽을 사용합니다. 단순 사각 ROI의 유무를 부품 검출로 해석하지 않습니다.

- 실물의 채도가 있는 영역과 CAD 부품 외곽을 비교하고, 각 부품의 노출 영역 안에서 색상 일관성과 부품 간 색상 경계를 비교합니다. 중앙 중단의 다른 색상은 하단만 있는 상태를 구분하는 근거입니다. 회색/흰색으로 동일하게 출력된 부품이나 조명 변화에는 근거가 부족할 수 있습니다.
- 보정·배치 오차를 고려해 기준 주변 최대 8mm 안에서 형상을 비교합니다. 관찰된 위치차는 표시용이며 로봇 목표를 수정하지 않습니다. 검색 범위와 표시 점수는 합격 공차·정확도 확률이 아닙니다.
- 일치도 50%, 형상 점수 32%, 경쟁 단계 점수 차이 2%p 이상이고 서로 다른 새 영상에서 두 번 연속 같은 상태가 나온 경우 단계 형상으로 표시합니다. 경쟁 후보가 비슷하거나 잘림·가림·대비 부족이면 재확인/판별 불가입니다. A/B 종류가 가까운 점수이면 우세한 종류를 `추정`으로 표시합니다.
- 상단 결합 외관을 찾아도 가려진 하단·중단은 `미확인`입니다. 제품 ID별 조립 이력이나 내부 안착·자석 결합 강도를 추정하여 PASS로 만들지 않습니다.

2026-10-07 사용자가 두 팔레트의 **하단+중단 조립 및 후진 위치**를 확인한 실제 영상 두 장으로 두 자리의 `중단 삽입` 분류를 확인했습니다. 이전 A 상단 결합/빈 팔레트 영상과 운반 지그의 여섯 부품 사진도 비교했습니다. 양산 정상/불량 전체 분포에 대한 검증이나 통계적 정확도 측정은 아직 없습니다.

## 앱에서 확인

앱을 다시 실행한 뒤 **상단 카메라 → 부품·조립 검사**를 선택합니다. 지그를 선택하지 않아도 운반 6자리·리니어 2자리·완성품 1자리를 함께 검사합니다. 오른쪽 표는 대상·판단·일치도를 보여주며, 행을 선택하면 근거를 볼 수 있습니다.

- **운반용 지그/완성품 팔레트:** 유효한 채택 위치를 우선 사용하고 청록 외곽과 XY·각도를 표시합니다. 채택이 없으면 최신 검출 위치를 사용합니다. 운반 지그는 앞뒤 방향 확인이 필요합니다. 채택 위치를 유지해도 현재 부품 판단은 새 영상에서 다시 계산합니다.
- **리니어 조립:** 기존 고정 배치와 전진 100mm / 후진 1.5mm 명령에 대응하는 캐리지 좌표를 재사용합니다. 실제 위치 센서값은 아닙니다. 명령 수신이 끊기면 마지막 목표임을 명시하고 해당 위치의 새 영상에서 형상을 비교합니다. 기록이 전혀 없으면 양쪽 목표를 표시하고 위치 선택을 기다립니다. 전진/후진 목표 선택은 표시·영상 비교용 미리보기이며 모터 명령을 보내지 않습니다.
- **CAD 설명:** 전체 배치, A/B 단계별 노출과 가림, 높이와 좌표를 확인합니다.

영상은 검출기가 늦어져도 계속 갱신합니다. 유효 기간 안의 채택 위치와 리니어 고정 좌표는 별도 기준으로 사용합니다. 영상 자체가 만료되면 이전 판단과 영상을 지웁니다. 분석은 최신 요청 하나만 보관하는 별도 작업으로 처리하며 화면 갱신과 로봇 제어를 기다리게 하지 않습니다.

## 전체 검사와 안착 기준 (2026-10-07)

- 초록: 지정 부품/조립 단계의 외관과 안착이 정상. 빨강: ROI 경계 걸침, 방향 차이, 다른 부품, 누락, 미완성 또는 형상 근거 부족. 노랑: 인접한 부품이 해당 ROI와 겹치지 않고 밖에 있음. 위치·영상 확보 전의 대기는 회색입니다.
- ROI는 팔레트 외곽 크기(운반/리니어 68mm, 완성품 70mm)에 고정합니다. 높이 있는 부품은 CAD 높이 범위까지 투영하여 시차로 인한 오판을 줄입니다. 부품 외곽이 경계에 걸치거나 사각 부품이 지그 축과 12° 초과 어긋나면 부정확한 안착으로 표시합니다. 원형/구형 중단은 각도를 검사하지 않습니다. 작은 독립 색상 노이즈는 제외하고 모든 위치의 경계 접촉은 1%까지 허용합니다.
- **완성품 팔레트는 `cap_added`만 정상 후보입니다.** 하단만 있거나 중단까지만 있으면 빨강 `미완성`입니다. 낮춘 점수 기준과 별도로, 영상에서 보여야 할 부품의 근거가 부족하면 정상으로 표시하지 않습니다. 가려진 내부 부품의 접촉·자석 결합은 이 화면의 확인 범위 밖입니다.
- 다른 자리의 부품도 함께 비교합니다. `appearance_reference.json`은 과거 정상 운반 배치에서 추출한 색상 보조 기준입니다. 사용자가 이번에 배치한 오안착/오배치 영상으로 정상 기준을 학습하지 않습니다. 색상은 CAD 형상과 함께 사용합니다.
- 리니어 두 중심은 지그 검출 탭과 조립 검사 탭 모두 하늘색 점으로 표시합니다. 현재 명령이나 선택한 목표가 없으면 임의 위치를 찍지 않습니다.

### 완성품 팔레트 위치 기준

사용자가 요청해 비워 둔 팔레트를 3장 촬영하여, `data/inspection_reference/pallet-empty.png`와 `pallet.json`에 **검사용 기준**을 저장했습니다. 내·외곽이 보이는 빈 팔레트에서 얻은 위치를 사용하며, 이후 영상에서는 제품 색상을 제외한 흰색 팔레트 외곽 특징만 추적합니다. 이때 제품을 놓으며 발생한 작은 이동·회전을 따라갑니다. 카메라·해상도 불일치, 부족한 추적점, 분산 부족, 크게 바뀐 크기는 추적 성공으로 처리하지 않습니다.

이 기준은 검사 화면 전용입니다. 티칭/모터 기준을 덮어쓰지 않습니다. 검출 결과가 없는 채로 제품 외곽을 팔레트 위치로 채택하지 않습니다. 빈 기준이 없을 때만 별도 외곽 추정을 사용할 수 있고, 표시에 그 출처를 남깁니다. 숫자 XY·각도는 지그 검출 탭과 같은 표시 좌표계를 사용합니다.

실제 확인 사례: 정상 안착한 B 완제품은 정상, 상단 없는 B 조립품은 미완성, B 하단 자리에 들어간 A 하단은 다른 부품, 비스듬한 A 부품은 부정확한 안착으로 확인했습니다. 재배치 때 관찰한 팔레트 이동은 영상 추정 약 1.3mm/1.6°였습니다. 통계적 정확도 수치는 측정하지 않았으며 표시 일치도는 정확도 확률이 아닙니다.

화면의 ROI는 한 높이의 점선 사각형, 부품은 윗면의 실선 비교선으로 표시합니다. 높이가 다른 점들을 합친 볼록 다각형은 안착 계산에만 사용하고 화면 외곽으로 그리지 않습니다. 따라서 실제 부품이 찌그러진 것처럼 꺾여 보이는 표시를 피합니다.

### 상단 단품과 중단 삽입 확인

리니어·완성품 팔레트에는 `cap_only` 비교 형상을 추가했습니다. 상단 단품은 높이와 형상을 비교하여 `상단 단품 · 미완성`으로 표시하며 완성품으로 통과시키지 않습니다. 중단 삽입 단계는 하단 전체 형상과 별도로 노출된 중단의 중심 편차(3 mm)와 시차 보정 외형 비율(기준 대비 1.20)을 확인합니다. 기울어진 삽입 또는 가림은 불합격이며, 가려진 내부 결합을 영상만으로 확정하지 않습니다.

실행 중 검사는 시작 전에 확정한 지그 좌표만 사용합니다. 지그 재탐지·외곽 추적은 실행 중 검사에 사용하지 않습니다.
