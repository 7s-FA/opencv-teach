# 지그 따라가기 계산

현재 구현: `so101_teach/geometry.py`의 `jig_delta`, `transform_jig_pose`, `corrected_step`.
위치 단위는 mm, 지그 각도 표시는 도, 역기구학 관절각은 라디안이다.

화면의 상단 기준 오른쪽X·위쪽Y 표시는 내부 로봇 좌표에서 `(X표시,Y표시)=(-Y로봇,X로봇)`로 변환한다. 표시 방향은 `(θ로봇+90°) mod S`, 회전 차이는 그대로다. 아래 계산식과 저장 데이터는 기존 로봇 베이스 기준을 사용하며 표시 변환은 구동 계산을 변경하지 않는다.

## 1. 지그 회전 차이

티칭 지그를 `(cx0, cy0, θ0)`, 실행 지그를 `(cx1, cy1, θ1)`로 둔다.
지그 대칭 주기 S는 정사각형90°, 직사각형180°, 방향이 구별되는 형상360°다.

`Δθ = ((θ1 − θ0 + S/2) mod S) − S/2`

따라서 외곽·내부 구조가 대칭이면90° 또는180° 회전을 별도로 구별하지 못한다.
비교 화면의 ΔX=cx1−cx0, ΔY=cy1−cy0는 지그 중심의 이동량이다.

## 2. 집게 끝 목표 위치와 자세

저장한 모터 틱을 3점 각도 보정으로 관절각으로 바꾸고, URDF 순기구학과 TCP 오프셋으로 티칭 집게 끝 p0와 자세 R0를 계산한다.
TCP는 현재 모델의 고정 집게 끝 기준이다.

```
x1 = cx1 + cos(Δθ)·(x0−cx0) − sin(Δθ)·(y0−cy0)
y1 = cy1 + sin(Δθ)·(x0−cx0) + cos(Δθ)·(y0−cy0)
z1 = z0
R1 = Rz(Δθ) · R0
```

즉 지그 중심에서 집게 끝까지의 상대 위치도 같이 회전시킨다. 지그 중심 이동량과 집게 끝 이동량은 회전이 있을 때 달라질 수 있다. 높이와 자세는 목표값이며, SO-101 관절 제약 때문에 실제 계산 결과에는 잔차가 남을 수 있다.

## 3. 역기구학으로 몸체 틱 계산

저장 관절각 q0에서 시작해 몸체 J1~J5에 대해 제한 범위 내 `least_squares`를 실행한다. J6 집게 벌림은 저장 틱을 그대로 사용한다.

최소화하는 잔차 벡터:

`[ex, ey, 2ez, 10φx, 10φy, 10φz, 0.05(q−q0)]`

- e: 계산한 TCP 위치 − 목표 위치(mm).
- φ: `log(R1ᵀ · R(q))`의 회전 벡터(라디안).
- 마지막 항은 티칭 관절각에서 지나치게 바뀌는 해를 약하게 억제한다.
- 제곱합을 최소화하므로 Z 위치 오차의 가중치는 X·Y의4배다. 위치와 자세는 서로 다른 단위의 수치 가중치다.

해를 모터 틱으로 반올림한 뒤 다시 순기구학으로 평가한다. 현재 계산 위치 오차가3mm 또는 자세 차이가45°를 넘으면 실행하지 않는다. 이 수치는 **모델 내부 계산의 허용값**이며 실물 정확도를 보증하지 않는다.

고정 스텝은 이 계산 없이 저장한 틱 그대로 실행한다. 동일 지그 위치·각도이면 보정 스텝도 저장 틱을 그대로 돌려준다. 영점, 3점 보정, TCP, 카메라→로봇 좌표에 실제 오차가 있으면 이동·회전 후 실물이 어긋날 수 있다.

## 보정 없는 비교 실행

`티칭 그대로 실행 · 보정 없음`은 저장된 스텝과 지그 기준을 유지하면서 이번 실행의 측정·IK만 건너뛴다. 전송 목표는 모든 스텝의 저장된 모터 틱이며 시작·종료 안전 자세도 포함한다. 실행 기록의 `execution_mode`는 `taught_ticks`이고, 측정하지 않았으므로 `measured_at`, 그룹의 `measured`와 `delta`는 null이다. 지그 보정 실행과 경로 미리보기는 별도의 측정·보정 절차를 따른다.

`티칭 그대로 실행 · 보정 없음`에서는 3D 지그도 카메라 감지값 대신 스텝에 저장된 초기 위치·각도로 표시하고 **지그: 티칭 저장 기준**이라고 명시합니다. 여러 지그는 각자 기준을 사용하며, 같은 지그의 기준이 스텝마다 다르면 진행 스텝에 맞춰 표시합니다. 종료 안전 자세까지 마지막 기준을 유지합니다. 지그 보정 전체 실행은 새 측정 위치를 사용하며, 갱신 정지 중 경로 미리보기는 고정한 위치를 사용합니다. 이 표시는 카메라 검출값이나 저장 데이터를 바꾸지 않습니다.

## 고정 위치와 실행용 측정

자동 갱신 정지 중 새 스텝 저장·개별 이동·경로 미리보기·리더 따라가기는 티칭 고정값을 사용한다. 고정값이 없는 지그는 이동·미리보기·따라가기에서 한 번 측정하며, 새 스텝 저장은 먼저 지그 다시 읽기가 필요하다. 여러 지그 중 새로 읽은 지그만 고정값에 추가한다. 전체 에피소드 실행은 실행용 위치를 새로 측정해 별도로 사용하고 티칭 고정값을 덮어쓰지 않는다. 지그 다시 읽기는 선택 지그의 고정값만 바꾸며 기존 스텝의 저장 기준은 유지한다.

검출은 측정할 때만 수행한다. 갱신 정지·실행 위치 고정 중에는 검출을 멈추고 카메라 화면에서 영상만 최대 5fps로 갱신한다. 새 측정은 최대 10fps이며, 화면 밖에서 측정·사진 작업도 없으면 카메라를 닫는다.

## 스텝별 티칭 기준의 수명

첫 지그 스텝은 확정된 측정값을 저장한다. 자동 갱신 정지 상태에서는 당시 확정한 지그 기준을 새 스텝에 저장하고, 갱신 중에는 같은 지그의 마지막 저장 스텝 기준을 이어 쓴다. 따라서 지그를 옮겨 재확정한 뒤 이어 티칭하면 같은 에피소드 안에서도 스텝마다 기준이 다를 수 있다. 기존 스텝 수정은 그 스텝의 기준을 유지하며, 다시 읽기·체크 전환·스텝 순서 변경은 이미 저장된 기준을 덮어쓰지 않는다. 마지막 관련 스텝을 삭제하거나 지그 따라가기를 해제하면 미사용 공통 기준을 정리한다.

현재 팔레트는 90° 대칭이며 89°→1°는 +2°로 보정한다. 운반용 지그는 A 상단의 고정 원형 구멍으로 360° 방향을 확인한다. 측정·저장 기준의 `mesh_yaw_offset_deg` 차이는 `pose_in_reference_basis`에서 먼저 반영한다. 현재 조립 모델은 180° 모델 방향 보정을 사용하므로 화면 약 119°와 내부 약 29°는 동일한 티칭 자세다.

현재 조립 STL은 `06a99f0b…`이며 새 B 상단 지그를 포함한다. 알려진 이전 조립 `b93ee6…`의 360°/180° 모델 보정 기준과 구형 운반판 `959603…`의 180° 대칭 기준만 검증된 호환 변환을 허용한다. 운반판 외곽·6개 장착 위치·A 방향 특징·검출 높이가 같음을 확인한 전환이다. 현재 A/B 에피소드의 참조는 새 모델로 이관되어 있으며 위치·각도·모터 틱은 유지됐다. 알 수 없는 해시나 방향 기준은 거부한다.

초기 최소제곱 해와 한계 여유 계산 뒤에는 위치를 유지하는 SLSQP 후보를 추가로 평가한다. 티칭 자세와 이전 스텝의 변화에 가까운 해를 선호하되, 위치·자세·평면 기울기·기계 한계 조건을 악화시킨 후보는 채택하지 않는다. `corrected_plan`이 PC 미리보기와 Pi 실행에서 동일한 순서로 이전 해를 전달한다.

## 몸체 관절 한계 여유

기존 TCP(현재 설정은 고정 집게 끝)를 유지한다. 기본 해에서 몸체 J1~J5 중 최소·최대에 3°보다 가까운 관절이 있으면, 몸체 관절 전체에 3° 여유를 둔 범위로 다시 계산한다. 개별 관절 틱만 잘라서 쓰지 않는다. J6 집게 벌림은 이 여유 정책에서 제외하고 저장된 틱을 유지한다.

전체 3° 여유가 어려우면 한계에 가까운 관절의 제한을 일부 풀거나, 공통 여유를 1°·0.5°로 줄인 후보도 계산한다. 여러 관절이 제한될 때는 확보 가능한 관절부터 여유를 찾는다. 보정 범위 자체가 6°보다 좁으면 해당 범위 안에서 가능한 여유만 시도한다.

반올림한 후보의 TCP 오차 ≤1mm, 자세 차이 증가 ≤1°, 전체 자세 차이 ≤45°일 때만 선택 대상으로 삼는다. 유효 후보 중 끝점에 0.15°보다 가까운 관절 수, 3°까지 부족한 여유의 합, 자세·위치 오차, 티칭 각도 변화 순으로 비교한다. 이렇게 찾아낸 해가 없으면 원래 기계 범위 내의 해를 유지하고 **3° 미확보: 관절 이름**을 표시한다. 수치 탐색 결과이며 전역 최적해나 물리적 도달 가능성을 증명하는 판정은 아니다.

기존 3mm 위치·45° 자세 실행 허용값과 실제 기계 한계를 넓히지 않는다. 지그가 동일한 경우, 고정 스텝, 보정 없는 실행은 원래 티칭 틱을 유지한다. 원본 티칭의 상대 위치를 임의로 지그 중심으로 바꾸지 않는다.

실행 기록의 `joint_margins_deg`는 반올림 후 J1~J5 각각의 가까운 한계까지 여유다. `low_margin_joints`는 3° 여유가 확보되지 않은 관절(반올림 허용 0.1°), `tilt_error_deg`는 목표와 계산 TCP의 Z축 방향 차이다. `limiting_joints`는 기록된 끝점에 2틱 이내로 가까운 몸체 관절이다. 기존 손목 여유 필드도 기록 호환을 위해 남긴다.

화면에 TCP 목표 오차·기울기·최소 관절 여유를 함께 표시한다. 이 수치는 모델 계산이며 실제 물체의 위치 오차와는 구분한다.

## 높이 기준

받침 높이는 설정된 기준면 0mm에 대한 값이며, 현재 설치에서는 작업대 윗면을 뜻합니다. 기준면보다 5mm 높은 받침이면 5mm를 입력하며, 빈칸은 0mm로 저장합니다. 현재 버거 위 운반판 아랫면과 작업대 윗면은 모두 실제 바닥 기준 195mm이므로 앱 받침 설정은 **0mm**입니다. STL 테두리 4.8mm를 더한 탐지 높이는 199.8mm로 약 200mm입니다. 상세 설치 기준은 `assets/carrier_assembly/README.md`를 따릅니다. 감지면 높이는 받침 높이와 STL의 바닥부터 테두리까지 높이를 더합니다. 내부 로봇 베이스 좌표와 기존 티칭 틱은 그대로 유지합니다.
