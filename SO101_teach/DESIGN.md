# SO-101 Teach 디자인 기준

## 최대화 작업 화면 · 2026-10-08

- UI 배치 기준은 최대화된 창(현재 PC 1920×1080)이다. 아래 과거의 최소 창 크기 기준보다 이 결정을 우선한다.
- 장비 모니터링은 두 팔의 상세 표를 나란히 표시한다. 별도의 선택 팔 상세 탭은 두지 않는다. 틱·각도·부하·전류·상태와 연결 정보·진단 안내를 같은 화면에서 확인한다.
- 에피소드 완제품 A/B는 검사 탭 바깥의 공통 설정이다. 시작 전 조건과 스텝 도착 후 검사는 구분한다. 리니어 팔레트는 좌측 A용·우측 B용으로 표시한다.
- Pi 실행 설정에는 속도·지그 측정 시간·측정 횟수·작업 제한시간만 둔다. 실행 중 지그 위치는 종료까지 고정하므로 `검출값 유지` 조절은 표시하지 않는다. 실행 전 측정 신선도에 쓰는 내부 값은 기존 값을 보존한다.

- 최대화 티칭 화면에서 에피소드·스텝 패널은 450px로 표시한다. 스텝 이름, 기준, 알림·검사 열의 가독성을 우선하고 3D 영역의 남는 가로 공간을 줄인다. 에피소드 조정의 설정 패널은 620px를 배정하고 3D 미리보기를 함께 유지한다.

## 조작 안내와 설정 초안

- 사용 안내의 첫 화면에 연결 설정 → 스텝 만들기 → 완제품·안착 검사 → Pi 내보내기 바로가기를 둔다. 상세 도움말은 그 아래에서 읽는다.
- 완제품·안착 검사·실행 설정 입력은 앱이 열린 동안 에피소드·스텝별로 유지한다. 미저장 항목과 저장·Pi 적용의 차이를 화면에 표시하고, 현재 입력을 저장값으로 되돌릴 수 있게 한다.
- 일반 스텝을 선택하지 않으면 검사 입력을 비활성화하며, 저장된 검사가 있는 스텝에만 검사 해제를 허용한다. 새 스텝에는 이전 스텝의 검사 입력을 복사하지 않는다.

이 문서가 새 앱의 디자인 기준이다. Python/Tk 네이티브 데스크톱 앱이며 기존 앱 실행 코드는 가져오지 않는다.

- 왼쪽 고정 메뉴: 티칭 / 상단 카메라 / 장비 모니터링 / 모델·계산 보정 / 설정·안내. 선택 상태는 배경과 텍스트 표시를 함께 사용한다.
- 티칭: 에피소드·스텝 목록 / 목표 틱 편집 / 오른쪽 넓은 3D. 6개 서보 모두 같은 단위.
- 장비의 현재값과 편집 목표는 구분한다. 미리보기·슬라이더는 모터 명령을 만들지 않는다.
- 스텝 자세 편집은 스크롤 없이 6개 관절을 고정 배치한다. 최소 창 1180×760에서도 모든 관절과 아래 저장·이동 버튼을 표시한다.
- 임의 이동/검증 완료를 암시하는 녹색 성공 표시를 피하고, 영상 형상 일치와 실물 좌표 검증을 구분한다.
- 가벼운 배경 #eef2f6, 흰색 카드, 짙은 메뉴 #132b3a, 선택/주요 버튼 #11697a, 본문 #142333, 보조 본문 #526477.
- 한국어는 Noto Sans CJK KR, 기본 11pt/제목 22pt. 수치는 정수 틱으로 표시하며, 작은 숫자 조절과 슬라이더를 함께 제공한다.
- 스텝 순서는 드래그로 변경하며 위/아래 버튼은 표시하지 않는다. Esc는 토크 해제 요청이다. 동작 정지·자세 유지와 토크 해제를 별도 버튼으로 구분한다. 하드웨어 비상정지라고 표시하지 않는다.

## 2026-09-23 상호작용

- 3D는 최대 30fps, 최신 대기 요청 하나만 유지한다.
- 모델·계산 보정도 설정 왼쪽·3D 오른쪽을 사용한다. 보정은 별도 파일에 저장한다.
- 검출 영상의 중심은 지그 방향에 맞춰 회전하는 단색 `+`로 표시한다. X·Y 글자·화살표는 생략한다. 주황색 연속 감지는 형상 일치와 구분한다.
- 지그는 10초 유지하며 실행 중 고정한다. 실물 실행 상태는 감지 유지 상태와 별도로 표시한다.

## 스텝 보정과 화면 정리

- `스텝 자세 편집` 상단에 `지그 따라가기`와 ON/OFF 설명을 둔다. 목록에는 고정/지그를 별도 열로 표시한다.
- 1280×800에서 6개 관절 조절과 6개 장비 상태 행을 모두 표시한다. 현재 틱은 관절 이름 옆, 편집 틱은 입력칸에 구분한다.
- 새 스텝 추가 / 선택 스텝 수정 / 실물값 불러오기 / 이 자세로 이동을 편집 패널 아래 2×2로 묶는다. 실물 자세 추가·Space는 스텝 자세 편집 하단의 저장 버튼 그룹에 배치한다. 실행과 편집은 계속 별개 명령이다.
- 이동 정지는 붉은 버튼, 토크 해제는 별도 버튼이다. 실제 중단 기준은 장비 화면에서 읽을 수 있다.
- 고정된 경고 배너는 페이지별 작업 안내로 바꾸며 실패 원인은 하단 상태 영역에 표시한다.
- 3D는 오른쪽을 유지하고 배경 대비를 높인다. Impeccable polish 기준을 적용했으며 새 디자인 시스템이나 의존성은 추가하지 않았다.

## 설정 기능 복원

- 다섯 번째 메뉴 `설정·안내` 안에서 로봇 / 3점 각도 보정 / 지그 / 카메라 / TCP / 도움말을 선택한다. 긴 설정은 스크롤하며 새 창을 띄우지 않는다.
- 파일·폴더 선택은 같은 설정 영역의 목록으로 연다. 저장·복사 등의 버튼은 입력칸 폭만큼 불필요하게 늘리지 않는다.
- TCP 모델 모드의 수치는 읽기 전용이다. 직접 설정 모드에서만 편집한다.
- 스텝의 지그 선택과 카메라의 범위 대상 지그를 구분한다. 안전 자세 설정은 기존 편집 영역에서 열고 3D를 유지한다. 적용은 시작·종료를 함께 갱신하며 지그 보정은 비활성화한다. 닫기는 편집 초안을 복원한다.
- 실물 속도 선택은 왼쪽 실행 버튼 바로 위에 두고 미리보기 배속과 구분한다.
- 미리보기 타임라인과 배속은 오른쪽 3D 아래에 둔다. 실물 실행·준비와 충돌하는 재생 조작은 잠시 비활성화한다.
- 데모는 상단에 USB 사용 안 함을 표시하고 저장 출처도 구분한다.

## TCP·지그 형상 설명

- TCP/지그 설정은 왼쪽 스크롤 입력, 오른쪽 고정 모델 미리보기로 구성한다.
- 파랑 A 모델 기준점과 주황 B 사용 TCP를 연결하고, 전체/끝부분 확대를 제공한다. 내부 링크명은 보조 설명에 둔다.
- 지그 형상 미리보기는 감지 위치와 구분한다. 가로·세로·전체 높이, 검출면 테두리 및 XY 축을 함께 보여준다.
- 입력 미리보기와 적용·저장을 분리한다. 미리보기는 모터/보정 파일을 변경하지 않는다.
- 두 설정 탭은 하나의 렌더 작업자를 공유하고, 보이는 모델의 변경 시에만 최대 30fps로 렌더한다.

## 조명·위치 갱신

- 티칭 3D 바닥은 밝은 무광 나무 질감이다. 상단 시점에서 바닥과 흰 지그의 세부 형상이 구분되어야 한다.
- 지그 표시 갱신은 0.35초 부드러운 전환을 사용한다. 표시 상태와 실행 측정값을 분리하며 실행 시 확정 좌표를 표시한다.

- 영상 갱신은 기존 Canvas 이미지 항목을 교체한다. 같은 표시 모드에서 자세를 편집할 때 이전 프레임을 지우지 않는다. 실물/편집 소스 전환과 수신 만료는 별도로 무효화한다.

- 시작 시 숨긴 창에서 레이아웃을 계산하고 첫 페인트를 준비한 뒤 표시한다. 종료 시 장치 정리가 끝나면 루트 창을 먼저 숨겨 자식 위젯 제거 중의 빈 밝은 패널이 노출되지 않게 한다.

## 3점 각도 보정

- 기존 설정 페이지 안에서 왼쪽 기록 양식·오른쪽 고정 3D를 사용한다. 선택한 서보를 청록색으로 표시한다.
- 몸체 5개는 0°·양쪽 각도, 집게는 −90° 기준·닫힘 최소·열림 최대를 기록한다. 집게를 선택하면 각도 입력을 읽기 전용 끝점 틱으로 바꾼다. 이후 몸체 한계 → 기록 확인·저장 순서로 안내한다.
- 현재 틱, 기록한 각도·틱, 접촉 최소·최대 틱을 구분한다. 각도 입력은 관절마다 유지한다.
- 모델 기준 자세 버튼과 실제 모터 적용 버튼을 구분한다. 저장 내용 확인은 파일 조회만 수행한다.
- 3점 보정 활성 시 시뮬 Δ틱 입력은 비활성화하고 이유를 표시한다. 측정한 각도 바깥의 계산은 추정으로 표시한다.

## 용어·상태 표시 점검

- 모델 보정이 화면 전용으로 오해되지 않도록 메뉴는 `모델·계산 보정`으로 표시한다. 화면에 적용되는 값과 실행 계산에 적용되는 값을 사실대로 설명한다.
- 실물 틱으로 그린 모델은 `실물값 보기`, 편집한 목표는 `스텝 자세`로 표시한다. 감지 범위·렌즈 보정·원시값 용어를 일관되게 사용한다.
- 하단 상태는 두 줄, 카메라 상태는 세 줄 공간을 확보해 문구 변경으로 작업영역이 흔들리지 않게 한다. 카메라 동작 버튼은 두 줄로 배치한다.

- 에피소드 삭제는 에피소드 그룹의 새로·저장 옆에 배치한다. 앱 내부 확인 패널에서 저장된 이름과 전체 스텝 삭제를 설명하고 취소·삭제를 구분한다. 별도 창은 열지 않는다.

- 리더·팔로워 보정 대상과 USB 포트를 같은 보정 화면에 표시한다. 대상 변경 시 다른 팔의 입력 파일·측정 내용을 남기지 않으며, 보정 중 대상과 포트는 고정한다. 첫 리더 보정도 팔로워 보정과 별개로 저장·등록한다.

- 영점은 관절 선택 옆의 `선택 관절 0° 기록`으로 한 개씩 기록한다. 선택 관절의 영점이 없으면 양쪽 각도 기록을 비활성화한다. 기준/보정 완료 수를 표시하고 음수 틱 < 영점 틱 < 양수 틱 조건을 안내한다.

- 보정 진행 기록은 리더·팔로워별로 저장한다. 재시작 시 읽기 전용으로 표시하고 `이어서 보정`을 누를 때만 모터 설정을 복원한다. 중단은 이전 서보 설정으로 돌아가되 진행 기록은 남긴다.

- 리더 연결 종료 원인을 표시하고 따라가기 버튼을 `리더 다시 연결`로 바꾼다. 읽기 연결 완료 후 명시적인 따라가기 입력을 받는다. 팔로워 한계에서 제한 중인 관절을 안내하되 다른 관절의 따라가기는 유지한다.

- 집게 접촉 부하는 로봇 설정 안에서 raw 단위로 조정한다. 기본값은 시험값임을 명시하고, 연결 상태에 `집게 접촉 유지`를 표시해 일시적인 전압 알림과 구분한다.

## 지그 이동 비교

- 티칭 화면3D 아래에 작은3행 비교표를 표시하고, 관절 편집과3D를 유지한다. 지그 보정 스텝이 없어도 제목과 상태는 남기고, 비교표는 사용자가 접고 펼친다.
- 지그·스텝 기준 그룹을 선택하고 티칭 기준/실행 측정/보정 차이를 구분한다. 실행시각·미리보기·실물 명령 전달·실패를 명시한다. 대칭을 반영한 회전 차이와 로봇 좌표계 mm를 사용한다.
- 새 측정 대기/실패 때 과거 측정값을 현재값으로 표시하지 않는다. 기록을 다시 볼 때 최근 실행임을 표시한다.

## 표시 좌표

- 현재 상단 카메라 기준 오른쪽X+, 위쪽Y+로 표시한다. 원점은 로봇 베이스이며 기존 내부좌표와 구분한다.
- 지그 위치·비교표·전역TCP 수치에 같은 변환을 적용한다. 중앙회전+와 좌상단고정축안내를 구분하고 로컬TCP/로봇보정입력은 좌표계를 명시한다.

- 지그 비교표는 감지값 비교/최근 실행을 구분한다. 감지값 비교는 카메라의 동일한 확정 위치와10초유지를 따르며, 새 위치 확정 때만 갱신한다. 실행/미리보기 중에는 실행에 사용한 값이 끝까지 유지된다.

## 티칭 기준 그대로 비교 실행

에피소드 실행 바로 아래에 `티칭 그대로 실행 · 보정 없음` 보조 버튼을 둔다. 두 버튼의 차이는 지그 측정·보정 여부이며, 원본 스텝이나 기준을 변경하는 체크박스와 혼동시키지 않는다. 연결 및 현재 자세 유지가 준비된 경우에만 활성화한다.

선택한 지그 보정 스텝의 초기 기준은 편집 패널에서 두 줄로 표시한다. 저장 초기 기준과 새 스텝 기준을 구분하고 카메라 연결 없이 읽을 수 있게 한다. 작은 창의 집게 슬라이더 공간을 확보하도록 설명 영역 간격을 줄였다.

보정 없는 실행의 3D 지그는 티칭 저장 기준을 사용하며 3D 아래 출처를 명시한다. 실시간 카메라 오버레이는 실제 감지값을 유지한다.

기준 미확정 상태에서는 체크 아래에 첫 지그 스텝 저장 시 위치·각도 확정이라고 표시한다. 체크만으로 카메라 기준을 기록하지 않으며, 첫 저장 뒤 저장 초기 기준 숫자를 보여준다.

실물 자세 추가 버튼 바로 위에 `Space 실물 저장 · Z 지그 전환` 안내를 둔다. Z는 누를 때 편집 체크박스만 전환하며, ON/OFF 상태를 하단에도 표시한다. 안내 공간을 위해 목록 주변 여백을 줄이고 3D·관절 편집 영역은 유지한다.

## 작업 화면 정리

스텝 삭제와 안전 자세 설정을 같은 줄로 묶고, 에피소드 복사는 새로/저장/삭제와 함께 위에 둔다. 미리보기 정지 버튼은 제거하고 재생 영역의 일시정지/이어보기를 사용한다. 하단 맨 오른쪽은 지그 다시 읽기다. 카메라 유지 시간 입력과 적용은 상단 카메라 도구모음에 둔다. 저장된 티칭 기준 덮어쓰기 버튼은 제거한다. 영상 저장 경로는 선택·복사 가능한 읽기 전용 입력칸에 표시하고 저장 폴더 열기 버튼을 제공한다. 사진 목록 및 파일 선택은 자체 스크롤바·휠 동작을 가지며 바깥 설정 페이지의 스크롤과 분리한다.

실물 자세 추가 버튼은 편집창 하단 전체 폭으로 두고 그 아래 새 스텝 추가/선택 수정 및 불러오기/이동 버튼을 배치한다. 감지 범위 해제 버튼은 제거하고 카메라 화면의 클릭으로 해제한다.

편집창 아래 동작 버튼은 왼쪽 목록창의 마지막 실행 버튼과 하단선을 맞춘다. 카메라 지그 외곽 옆에 표시 좌표 X·Y(mm)와 방향을 두 줄로 표시한다. 카메라 영상과 저장 PNG는 같은 합성 이미지를 사용하며 감지 범위까지 포함한다. 수동 촬영 이미지는 data/captures, 측정 JSON은 그 하위 metadata로 분리한다.

라즈베리파이 연결 준비는 설정·안내의 별도 내부 탭으로 둔다. SSH 확인 성공과 원격 티칭 구현 상태를 구분하고 현재 로컬 연결 대상을 그대로 유지한다. 바닥 보정 입력은 기본 0mm이며 내부 기본 기준면 −7.4mm와 구분하고 3점 보정에서 별도 검증 각도 입력·비교 버튼을 제거한다.

티칭의 에피소드 카드는 275px, 스텝 편집 열은 최소 310px(카드 298px)로 확보한다. 나머지 가로 공간은 오른쪽 3D가 사용하며 최소 창에서도 비교표·관절·하단 버튼을 유지한다.

지그 보정 결과에는 TCP 위치 오차와 집게 축 기울기 차이, 몸체 5개 관절 중 최소 한계 여유를 함께 표시한다. 3° 여유를 확보하지 못한 관절 이름을 같은 상태 문구에 표시하며 추가 확인 창을 만들지 않는다.


## 로봇팔 선택

- 상단에서 로봇팔2·3을 선택하고 기존 티칭·설정 화면을 재사용한다. 한 번에 한 팔만 제어한다.
- 팔별 에피소드 ID와 보정 진행을 구분한다. 기존 미지정 기록은 팔2 전용이다.
- 보정 전 팔3에는 `보정 필요`를 표시하고 해당 팔의 보정 화면으로 안내한다. USB 포트의 고유 끝자리도 표시한다. 초기 연결용 파일을 실측 보정처럼 사용할 수 없게 한다.
- 읽기 연결은 토크 OFF를 확인한 뒤 정리하고 전환한다. 동작·자세 유지·보정 중에는 전환하지 않는다.
- 전체 작업대는 공통 좌표를 유지한다. 선택한 팔의 관절/TCP와 다른 팔의 예시 자세를 구분한다.

## 현재 보정 화면과 조립 모델

- 기준 각도/읽은 각도는 30pt 굵은 청록색 숫자로 분리한다. 측정이 없거나 입력 오류이면 이전 숫자를 유지하지 않고 `—`로 표시한다.
- 팔3 보정 기본 시점은 벽 반대편의 측면이며, 다른 팔2는 유효한 저장 안전 자세로 표시한다. 시뮬 동작과 실제 구동을 구분한다.
- 지그 관리의 등록 운반형 지그는 메인 시뮬과 같은 조립 함수를 사용한다. 버거·고정부·모델 방향 보정이 화면별로 달라지지 않게 한다. 외부에서 STL이 같은 경로로 갱신돼도 미리보기를 다시 읽되, 등록값 저장은 별도 동작이다.
- 설정 화면은 세로 스크롤을 허용한다. 작은 창에서도 쓰기·보정 적용 버튼의 의미가 잘리지 않도록 문구를 줄바꿈하고 작업 버튼을 별도 행에 배치한다.

## 상단 카메라의 부품·조립 검사

- 상단 카메라에 지그 검출 / 부품·조립 검사 두 하위 탭을 둔다.
- 부품·조립 검사는 카메라 영상과 CAD 설명을 전환한다. 영상 아래 표에 대상·판단·일치도·근거를 나란히 표시한다.
- 유효한 채택 위치를 우선 표시하고, 없으면 최신 감지를 사용한다. 카메라 보정·운반 지그 방향이 없으면 대기 사유를 표시한다.

## Pi 에피소드 전송

- 티칭 왼쪽 에피소드 저장 버튼 아래에 `Pi 에피소드 내보내기`를 둔다.
- 설정·안내의 `에피소드 전송` 탭에서 선택 팔·이름·스텝 수, Pi 주소, 현재 A/B 연결과 실행 설정을 확인한다.
- 조회 후 `Pi로 전송 · A/B 실행 연결`을 명시적으로 실행한다. 진행·실패·완료 상태는 같은 화면에서 표시한다.
- 전송 중 입력 대상 변경·중복 전송을 막고, 실패 시 다시 조회할 수 있게 한다. 저장된 스텝과 편집 중 자세, 전송 완료와 실물 실행을 구분한다.

## 카메라 화면 갱신 비용

- 현재 선택한 지그 검출 / 부품·조립 검사 탭의 영상만 그린다. CAD 설명은 영상 도착으로 다시 그리지 않는다.
- 새 영상은 즉시 반영하고 같은 영상의 반복 메타데이터 갱신은 최대 5 FPS로 묶는다. 만료된 영상·검출은 먼저 제거하며, 채택·티칭 유지 표시는 별도 만료 주기를 유지한다.
- 카메라 화면 축소는 bilinear로 처리하고 저장 원본·메타데이터와 3D 렌더 품질은 유지한다.

- ROI 탭은 영상과 검출 결과의 시간을 따로 판단한다. 영상이 최신이면 검출 갱신 대기 중에도 계속 표시하고, 만료된 ROI만 숨긴다. 영상 자체가 만료됐을 때만 영상을 지운다.

- 부품·조립 검사 표는 형상 일치·부품 없음·조립 단계·확인 중·판별 불가를 텍스트와 색상으로 구분한다. 청록선은 기준 지그 위치, 녹색은 확인된 형상, 주황색은 확인 중인 영역이다. 가려진 부품과 물리적 결합 성공을 확정하지 않는다.
- 영상 라벨은 한국어 대상명과 현재 영상 판단을 사용한다. 반복되는 라벨 이미지는 캐시하여 매 프레임 글꼴 처리를 반복하지 않는다.

- 리니어 팔레트 2개는 전후진 명령의 고정 좌표를 사용한다. 명령 미확인/마지막 명령/목표 미리보기와 실제 명령 수신을 구분한다.
- 형상 분류는 별도 최신 요청 작업으로 제한하고 연속된 새 영상 두 장을 확인한다. 위치차·일치도는 표시 근거이며 동작 목표·공정 합격 판단에 사용하지 않는다.

- 부품·조립 검사는 지그/제품 선택 없이 9개 영역을 동시에 보여준다. 우측 고정 표에서 전체 상태를 비교하고 선택 행 아래에 근거를 표시한다.
- 정상은 초록, 비정상(경계 걸침·기울어짐·다른 부품·누락·미완성)은 빨강, ROI 밖은 노랑, 입력 대기는 회색으로 구분한다. 완성품 자리에서는 상단 결합 외관만 정상 후보이다.
- 지그 검출과 조립 검사 모두 동일한 리니어 목표 좌표로 두 중심점을 표시한다. 명령이 없을 때 임의 좌표를 표시하지 않는다.
- 완성품 팔레트의 빈 기준 사진과 현재 흰색 외곽 추적을 연결한다. 제품 픽셀로 기준 위치를 이동시키지 않는다. 검사 기준은 모터·티칭 기준을 변경하지 않는다.

## 전체 UI 정렬 · 2026-10-08

- 최대화된 에피소드 조정은 왼쪽 에피소드·스텝 목록, 가운데 완료 알림·실행/검사 설정, 오른쪽 기존 3D 미리보기를 함께 표시한다. 선택 스텝과 미리보기는 같은 저장 자세를 사용하며, 실물 실행 버튼은 자세 편집 화면에 둔다.

- 일반 입력칸·선택 상자·수치 입력·버튼은 같은 글꼴 계열과 높이를 사용한다. 관절 편집용 작은 입력과 티칭 목록의 작은 버튼은 밀집 배치를 유지한다. 탭 선택은 흰색 배경과 청록 글자로 표시한다.
- 카메라의 두 탭은 같은 바깥 여백을 사용한다. 부품·조립 검사 도구모음은 왼쪽 표시 모드·검사 설명, 오른쪽 리니어 위치·연결 버튼을 한 줄에 정렬하고 상태 설명은 아래 행에 둔다.

- 지그 검출 목록의 일반 상태 표시는 초당 1회로 제한하고 오류·영상 끊김은 즉시 표시한다. 현재 상태의 소수점 경과 시간은 생략한다. 채택 열은 짧은 요약을 쓰고, 행 선택 시 고정 높이의 상세 영역에 원문 사유와 관측 정보를 표시한다.

- 시작 전 검사는 검사 가능한 대상을 함께 계산하고 부품별 최소 판정 횟수를 표시한다. 최소 판정은 기본 2회, 2~10회로 설정하며 결과 없음은 횟수에 포함하지 않는다. 제한시간과 최소 판정 입력을 나란히 두고, 검사 목록에는 두 값을 함께 표시한다.

## 2026-10-08 전체 UI 정렬

- 목록·상세·설정의 스크롤바는 내용이 화면을 넘을 때만 표시한다. 짧은 설정 화면을 빈 영역까지 스크롤하지 않는다.
- 카메라 검사 근거는 글 길이에 맞춰 2~5줄로 표시하며 긴 내용은 스크롤한다. 지그 상태 목록은 영상 높이만큼 빈 행을 늘리지 않는다.

- 장비 모니터링은 두 팔의 표와 연결·진단 정보를 위쪽에 모으고, 값·수신 기준과 동작 중단·도착 기준을 나란히 표시한다. 자세 편집 슬라이더 등 값 조작은 유지한다.

## 에피소드 전송과 화면 비율 · 2026-10-08

- 에피소드 전송은 설정 메뉴가 아니라 에피소드 조정의 세부 탭이다. 왼쪽에서 선택한 에피소드를 동일 ID로 저장·갱신하고 기존 A/B 실행 연결을 유지한다. 새 에피소드는 목록에 추가한다. 실행 설정의 동시 적용은 기본 해제된 별도 선택으로 제공한다.
- 시뮬레이션 출력은 960×540(16:9)으로 상단 카메라 1280×720과 비율을 맞춘다. 확대·축소는 비율을 유지하며 시야각 계산도 출력 비율을 따른다.

## 검사 표시와 스텝 자세 미리보기 · 2026-10-08

- 스텝 검사는 검사가 표시된 스텝의 도착 확인 직후 시작한다. 이전 방식의 에피소드는 검사와 이에 연결된 완료 알림을 다음 스텝으로 한 번 옮겨 실제 시작 시점을 유지한다.
- 스텝 자세와 경로 미리보기의 리니어는 팔2 전진 목표, 팔3 후진 목표를 표시한다. 실물값 보기는 실제 명령 위치를 유지한다.
- 3D 원점·TCP·지그 중심의 투영은 실제 렌더 영상의 가로·세로 비율을 사용한다.
