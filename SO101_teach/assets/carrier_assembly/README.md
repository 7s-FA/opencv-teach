- `carrier_assembly.3mf`: 같은 배치의 구성품 7개를 분리해서 보존한다.
- `assembly.json`: 각 부품의 이름, 원본 해시, 이동·회전, 설치 높이.
- `source/current/`: 이번 재생성에 사용한 최신 원본 7개. 상위 `source/`의 예전 복사본은 이전 기록으로 보존하며 이번 빌드에서 사용하지 않는다.
- `preview.png`, `top_view.png`: 사시도·평면도. 색상은 부품 구분용이다.
- `validation.json`: 파일과 조립 치수 검증 결과.

## 배열과 조립 좌표

운반판의 장축이 가로가 되도록 본 평면도에서 **위쪽은 B 상단·B 중단·B 하단**, **아래쪽은 A 상단·A 중단·A 하단**이다. 카메라 원본에서는 운반판이 회전되어 보인다. 사용자가 확인한 버거 정면 카메라를 기준으로 A가 앞줄, B가 뒷줄이다. 버거 전방 +X는 운반판의 −Y를 향하며 기존 장착각 −90°를 유지한다.

| 위치 | 부품 | 원본 복사본 | 중심 X, Y (mm) | Z축 회전 |
|---|---|---|---|---|
| 위 왼쪽 | B 상단 | `source/current/b_cap_jig.stl` | -72, 36 | 90° |
| 위 가운데 | B 중단 | `source/current/b_tpu_jig.stl` | 0, 36 | 90° |
| 위 오른쪽 | B 하단 | `source/current/b_housing_jig.stl` | 72, 36 | 90° 추정 |
| 아래 왼쪽 | A 상단 | `source/current/a_cap_jig.stl` | -72, -36 | 90° |
| 아래 가운데 | A 중단 | `source/current/a_ball_jig.stl` | 0, -36 | 90° |
| 아래 오른쪽 | A 하단 | `source/current/a_housing_jig.stl` | 72, -36 | 90° 추정 |

원점은 운반판 중심, Z=0은 운반판 아랫면이다. X는 장축, Y는 단축이다. 지그 바닥판은 각각 68×68mm이고 중심 간격은 72mm, 인접 판 사이 간격은 4mm다. 각 지그는 삼각형 메시의 수직 접촉 계산에 따라 Z=4.8mm에 놓였다. 전체 외형은 **220×148×31.3mm**다.

2026-10-02 추가 갱신: 새 B 상단 지그 원본(SHA-256 `866f9a7f…`)을 반영했다. 완성품 STL은 `06a99f0b…`로 변경됐으며, B 상단의 내부 형상만 달라졌다. 운반판 외곽, 지그 6개의 중심·설치 높이, A 상단의 방향 검출 구멍은 이전과 같다. A/B 하단은 최신 원본 파일명에 맞춰 배치한다.

하단 지그의 세부 방향은 제품에 가려져 사진에서 완전히 확인되지 않아 기존 90° 배치를 유지했다. 접착제·테이프 두께와 출력 공차는 모델에 포함하지 않았다. STL은 접촉하는 개별 셸을 유지한 조립 메시이며, 일체형 출력용 불리언 합집합 솔리드는 아니다.

## 실제 설치 높이

사용자가 정한 높이는 **실제 바닥 기준**이다. 운반용 지그는 작업대 위가 아니라 **터틀봇 버거 위에 장착**된다.

| 기준 | 실제 바닥에서 높이 |
|---|---:|
| 작업대 다리 결합 높이 | 185mm |
| 작업대 판 두께 | 10mm |
| 작업대 상판 윗면 | 195mm |
| 버거 위 운반 지그의 탐지용 외곽 테두리 | **199.8mm ≈ 200mm** |
| 운반 지그 아랫면 | 195mm |

STL의 탐지 테두리는 로컬 Z=4.8mm다. 사용자 최종 지정에 따라 운반판 아랫면은 작업대 윗면과 같은 195mm에 두고, 앱의 **받침 높이는 0mm**로 설정한다. 테두리는 `195 + 4.8 = 199.8mm`로 약 200mm다. 내부 부품 지그의 최대 높이 31.3mm를 탐지 테두리 높이로 사용하지 않는다.

기존 카메라·로봇 좌표는 작업대 윗면을 `table_z_mm=-7.4`로 사용한다. 이 좌표계를 유지하면 실제 바닥은 로봇 기준 Z=-202.4mm, 운반판 아랫면은 -7.4mm, 탐지 테두리는 **-2.6mm**다. `support_height_mm=0`은 작업대 윗면과 높이가 같다는 뜻이며, 실내 바닥에 운반판을 놓는다는 뜻이 아니다. 실제 바닥 기준 설치 높이는 `physical_installation`에 따로 기록한다.

작업대 두께와 운반 지그 높이는 사용자 지정값이다. 카메라 외부 파라미터는 기존 CAD 추정값이며, 이번 작업으로 로봇 동작 정밀도까지 실측 검증한 것은 아니다. 카메라 영상 검증은 저장한 최신 프레임을 사용한다.
