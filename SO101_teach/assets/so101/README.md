# SO-101 티칭 모델 · 손목 카메라 없음

2026-09-21부터 티칭 GUI는 상단 카메라를 사용합니다.
3D 모델에서 **RealSense D435, 카메라 마운트, 부착 나사 머리 5개, 와셔 2개**와 해당 전용 메시를 제거했습니다.
SO-101 본체와 XLeRobot 고정·가동 홀더 및 파란 TPU 손가락 2개는 유지합니다.
Final_Arm의 Demo·Sim_real 원본 모델은 변경하지 않았습니다.

- `so101_modified.urdf`: 원본 관절 구조와 기구학 계산 기준입니다.
- `so101_modified.xml`: MuJoCo 3D 표시용 모델입니다.
- `preview_scene.xml`: 조명과 바닥을 포함한 화면입니다.
- `provenance.json`: 원본 출처 및 현재 파일의 해시입니다.

관절 위치는 선택한 팔의 정수 모터 틱과 해당 영점·3점 각도 보정으로 계산한다. 몸체 5개 관절은 구간별 선형 각도 변환을 사용한다. 집게는 −90° 기준 2047틱과 닫힘·열림 범위를 별도로 저장하며, 일반적인 0~100 표시값으로 변환하지 않는다.

TCP 계산 기준은 `gripper_frame_link`다. 고정 집게 끝단은 이 프레임에서 약 (+1.773410, +0.602657, +6.549655)mm이며, 고정 집게 중앙은 (0,0,0)이다. 설정에서 선택한 TCP를 표시와 계산에 동일하게 적용한다. 모델 TCP는 조립 메시에서 계산한 기준이며 실물 오차는 별도 실측 항목이다. 3점 보정이 있으면 관절 Δ틱을 중복 적용하지 않는다. 미리보기 자체는 모터 영점이나 EEPROM을 변경하지 않는다.

이 모델은 위치·자세 표시용입니다. 충돌·접촉·TPU 변형·실물 파지 판정을 수행하지 않습니다.

실물 실행 FK·IK는 기존 URDF와 `ModelReference`를 사용한다. 3D 화면은 해당 틱에 `assets/joint_alignment/`의 표시 보정을 추가로 적용할 수 있다. 표시용 각도 보정과 사용자가 설정한 TCP·모델 기준은 구분하며, 표시 보정을 변경해도 실제 모터 목표 틱이나 영점·EEPROM을 변경하지 않는다.
