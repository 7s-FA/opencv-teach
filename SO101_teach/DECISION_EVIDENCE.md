# 공정 판정 영상 기록

A/B 공정 실행은 지그 위치 판정과 시작 전·공정 중 안착 검사에 사용한 입력을 `data/diagnostics/decision-evidence/<run_id>/` 아래에 저장한다. `jig-<session_id>`는 카메라를 처리하는 실행부의 data 폴더, `inspection-<session_id>`는 공정 실행기의 data 폴더에 생성된다. 팔별 data 폴더가 다를 수 있으므로 실행 기록의 `analysis.artifacts.decision_evidence`에 기록된 manifest 경로를 사용한다. 실패 보관 `error.json`의 `decision_evidence`에도 실제 검사 프레임과 세션 참조가 남는다.

이 기록은 판정 입력으로 사용하지 않는다. 검출 임계값, CAD 정합, 시간 누적, 영상 신선도, 위치 확정 및 모션 조건은 기존 구현을 따른다.

## 파일

- `manifest.json`: 실행·프로필·지그 문맥, 보존된 프레임 목록, 소비한 판정과 집계, 누락·저장 오류.
- `<frame_id>/frame.png`: 알고리즘에 전달한 BGR 픽셀을 무손실 PNG로 보존한 영상.
- `<frame_id>/masks.npz`: 그 처리에 실제 사용된 AI 인스턴스 마스크와 지그 추적 검색 마스크. `allow_pickle=False`로 읽는다.
- `<frame_id>/frame.json`: 원래 캡처 시각, 픽셀/파일 해시, 마스크 배열명·클래스·신뢰도·박스·해시, 프레임별 검출 결과와 거절 이유.

`session`과 `frame_id`가 영상·마스크·판정의 연결 키다. 지그 기록에는 처리 결과(`live_by_jig`), 누적 결과(`by_jig`), 추적 소실/후보 없음에 따른 초기화 사유가 포함된다. 공정 실행기가 소비한 결과는 별도 `jig_consumer` 항목에 연결되며, 실제 채택 여부·신선도·부족한 지그가 남는다. 안착 검사는 `inspection_decision`에 최소 관측 수, 누적 개수, 시간 조건, 판정 이유·오류가 연결된다. 처리됐지만 문맥 변경으로 폐기된 결과는 `inspection_publication.published=false`로 구분한다.

AI를 새로 실행하지 않은 추적 프레임에는 이전 AI 마스크를 붙이지 않는다. 대신 `no_new_inference`와 그 프레임의 검색 마스크를 저장한다. 모델 오류나 아직 분류를 요청하지 않은 프레임도 그 상태를 명시한다.

지그 카메라 경로는 카메라 입력 픽셀을 저장한다. 안착 검사 경로는 전송 이미지 해독 후 **검사기가 실제 받은 픽셀**을 저장한다. 원래 전송이 JPEG였다면 그 이전 센서 영상을 복원하는 기능은 아니다. 저장할 때 추가 JPEG 손실 압축은 하지 않는다. 캡처 시각은 원 입력의 단조 시각을 보존하며 다른 호스트의 단조 시각과 직접 빼지 않는다.

## 용량과 오류

세션마다 최근 64개 처리 프레임, 프레임 파일 합계 128 MiB를 보존한다. 초과한 오래된 프레임은 해당 세션 안에서만 제거하고 `rolling_retention`을 남긴다. 다른 실행 세션이나 사용자 파일을 삭제하지 않는다. 전체 실행 이력에 대한 자동 삭제 정책은 이 기능에 포함하지 않는다.

입력 영상·마스크 대기 버퍼는 32 MiB와 64항목으로 제한한다. 메타데이터와 최근 판정 메모는 별도이며 판정 메모는 256항목, 최근 누락 사유는 128항목, 오류 메시지는 16항목을 보존한다. 총 누락/퇴출 개수는 따로 유지한다.

큐가 가득 차면 판정을 기다리게 하지 않고 해당 프레임 기록의 누락을 표시한다. PNG/NPZ/JSON 저장·디스크 오류는 판정 결과를 바꾸지 않는다. `complete=false`, `errors`, `dropped_frames`, `gaps`를 확인해야 하며, 기록이 없다는 사실을 미검출 판정으로 해석하면 안 된다. 종료 시 최대 2초(실행부의 카메라 모드 변경 응답에서는 0.2초)만 저장 작업자를 기다린다. 남은 작업은 같은 프로세스의 작업자가 계속 마무리한다. 종료 전에 프로세스가 강제 종료되면 미완료 manifest가 남을 수 있다.

## 재현

`frame.png`를 OpenCV BGR로 읽고 `pixel_sha256`를 확인한다. `masks.npz`의 배열을 `frame.json.ai_instances`의 클래스·신뢰도·박스에 연결한다. 저장된 프로필·지그·동일 STL과 코드 버전을 사용해야 한다. 저장 중 추가 촬영이나 AI 재추론을 수행하지 않으며, 원본과 다른 마스크를 만드는 필터를 적용하지 않는다.

이번 검증 자료는 `verification/decision-evidence-20261026/`에 있다. 장치를 열지 않는 단위 검사는 `tests.test_decision_evidence`에 있으며, 실제 실패/지그 확정 저장 영상 5장의 변경 전후 판정 및 저장 파일 재생 비교는 `replay_evidence.py`로 수행했다.
