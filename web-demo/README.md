# SO-101 Teach 웹 데모

화면의 기준은 상위 프로젝트의 `SO101_teach/DESIGN.md`입니다. 1920×1080 데스크톱 GUI의 메뉴·탭·3열 티칭 배치와 버튼 이름을 우선합니다. 화면이 좁으면 같은 패널을 세로로 배치합니다.

- 실제 URDF/STL과 데스크톱 작업대의 정적 모델을 사용합니다.
- 팔별 보정값으로 편집 틱을 관절 각도로 변환합니다. 상대 팔은 저장된 시작 안전 자세를 표시합니다.
- 에피소드 선택·복사·스텝 편집·순서 변경·브라우저 저장·초기화·JSON 내보내기를 지원합니다.
- 경로 미리보기는 스텝 자세를 차례로 표시합니다. 실물 실행기의 속도 계획·역기구학·충돌 계산을 재현하지 않습니다.
- 카메라 화면은 저장된 사진의 지그 검출 및 검사 결과를 보여 줍니다. 실시간 OpenCV 검출을 웹에서 실행하지 않습니다.
- 지그 보정 원리 체험은 2D 강체변환과 90°/180°/360° 대칭 방향을 계산합니다.
- 하드웨어 조작과 미구현 설정은 비활성화합니다. 실물 연결 상태나 센서 측정값을 임의로 생성하지 않습니다.

```bash
npm ci
npm run dev
npm test
npm run build
```

Node 22 기준. GitHub Actions에서 검사·빌드 후 Pages로 게시합니다. 공개 자산에는 인증 정보·네트워크 주소·장치 식별자가 없습니다.
